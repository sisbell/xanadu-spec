# ASN-0129: Substrate Predicate Composition

*From atomic predicates to the substrate's full query language — Boolean composition, quantification, aggregation, and the expressive ceiling.*

ASN-0128 ships the atomic read surface of the typed-relation substrate: per-type default predicates (D1–D3), behavior-unlocked predicates (BH1–BH4), the address-denotation discipline that types their arguments and results (AD/AM), and the three result-set views (audit, active, default). Each atom is specified singly. This note closes the chain: it defines what is expressible *from* the atoms — the algebra of Boolean composition, finite quantification, value composition, and aggregation under which the atomic vocabulary generates the substrate's full predicate language — and fixes the ceiling: under the read base and evaluation class PC6 fixes, the language is *exactly* that closure (PC6).

The consumers are protocols: any coordination machinery built over the substrate — triggers ("act when P"), termination conditions ("stop when Q"), gating disciplines — is *written in* this language. PL is thereby the substrate's *extension language*: a builder registers types and composes predicates, and composition is the **only** extension mechanism — why the guarantees below hold for every predicate any builder will ever write. This note supplies the complete predicate foundation.

**Depends:** ASN-0034 (Tumbler Algebra), ASN-0043 (Link Ontology), ASN-0086 (Typed Relations on Address Sets), ASN-0126 (Substrate Shape Framework), ASN-0127 (Content-Region Link Query — boundary only — see Structural reads only), ASN-0128 (Substrate Type Operational Semantics), ASN-0134 (Substrate Consistency and Isolation Model — PC4).

## What this note commits

- **The atomic vocabulary, generated** (V, V-AUD, V-TUP, V-PRIM, V-DOC, V-STAT): per-type template families derived from the registration records, plus this note's fenced admissions (V); staticity is a theorem of registry invariance.
- **Four composition primitives** (PC0, PC1 with V-IDX, PC2, PC2a, over QD with QD-refl): Boolean closure, finite quantification, guarded value composition, and aggregation — QD's bases audited against the upstream read surface (QD-audit), set-semantics counting settling ASN-0128 Open Question 2, and the typing judgment defined and decided (WT).
- **Three-view parametricity** (PC3, UV): one view per term, with UV's per-codomain default-view rule settling ASN-0128 Open Question 1.
- **Evaluation guarantees** (PC4, PC5): purity and termination for every PL term at every reachable state.
- **The ceiling** (PC6, PC6a, C-reach, C-emit): syntax-directed evaluation over the substrate's read base denotes exactly PL; the grammar ships no fixpoint operator; reach- and self-emit-inexpressibility are conjectured, deliberately not promoted to theorems.
- **Predicate dynamics** (FP, PD0, PD1, PD2): monotone, non-monotone, and frame-stable term classes — the stability theory a protocol author needs to choose trigger and termination predicates soundly.

## The atomic vocabulary

ASN-0128's registration record `(shape, idem, behaviors)` determines, per registered coverage class K, which read predicates exist. We make the determination a generator.

*States and signatures.* Throughout, `S` is the class of reachable substrate states — ASN-0128's `→_sh*`-reachable extended-record states (R-TR), reached from R-VAL's `Σ_init` — ranged over by Σ. Every atom and every PL term is `S`-indexed: a term denotes a function of its arguments and the state. Atom signatures elide the `S` argument by convention — `is_K : T → Bool` abbreviates `is_K : T × S → Bool` — and the composition rules write `S` explicitly where their typing turns on it (PC0–PC2a).

**V (AtomicVocabulary).** For each registered K, the *template family* `Tpl(record(K))` is:

- *Core family* — present for every K, whatever the record: the membership atom `is_K : T → Bool` (D2, ASN-0128) and the enumeration atoms `members(K, view) : ℘_fin(T)` (D1) and `targets_of(x, view) : T → ℘_fin(T)` (D3). For Unary K, `targets_of` is constantly ∅ (D3); the template still instantiates — degenerately, not absently.
- *BH1 family* (when read-filter is attached): `is_filtered : T → Bool`.
- *BH2 family* (when determinate-walk is attached): `succs : T → ℘_fin(T)`, `chain : T → Seq_fin(T)`, `tip : T → T ∪ {⊥}`, `is_in_chain : T × T → Bool`.
- *BH3 family* (when typed-reverse-lookup is attached): `sources_to : T → ℘_fin(T)` and `target_of : T → T ∪ {⊥}`, class-indexed like every other family member; and the join `targets_keyed : T → Map_fin` — *class-unindexed*: a single global atom joining `target_of` across every BH3-attached Binary type (FP), which each BH3-attached class's family contributes identically, the union over K collapsing the contributions to one symbol — in `V_atom` iff some registered class attaches BH3.
- *BH4 family* (when age-staleness is attached): `age : T → ℕ ∪ {⊥}` and `stale : ℕ → ℘_fin(T)`. ASN-0128 types `age` as a partial function into ℕ, defined on active tuples only; PL totalizes the same graph by adjoining the verdict — `age(a) = ⊥` exactly when `a` is not the address of an active K-tuple. The re-typing is conservative (no defined value changes) and load-bearing: an unguarded partial atom would make definedness *state-dependent* — a retraction turning a defined term undefined — poisoning PC4/PC5's universal claims and the dynamics classification with them. With ⊥ a value, PC2's guard discipline applies unchanged. (The test `age(a) ≠ ⊥` (V-PRIM) doubles as a tuple-address activeness test.)

The atomic vocabulary is `V_atom = ⋃_{K registered} Tpl(record(K)) ∪ V-TUP ∪ V-PRIM ∪ V-DOC` — the template families together with the per-tuple projections (V-TUP), the state-independent primitives (V-PRIM), and the residence atom (V-DOC) defined below; each template atom's *active*-view semantics is exactly its ASN-0128 specification, and the core family's default reading is likewise inherited (BH1's rewrite scope, ASN-0128); the behavior atoms' default-view readings are this note's own, fixed at UV — ASN-0128 left them open (its Open Question 1). The `idem` component contributes no atom: it is emit-side machinery (I1, I6), and its one read-side consequence — at-most-one active tuple per I0-class along surface-emitted derivations (I1a) — is a property of states, not a predicate former. Write operations (`Emit_K`, `Nullify_Binary`, `retract_stale`) are outside `V_atom` by construction: predicates read.

Atoms may be *internally iterative* (`chain`), bounded behind the atom's own termination proof.

**V-AUD (AuditReadings).** The core family's readings at view `audit` — a view PC3 gives every term — are the lift of D1–D3 from the active slice to the audit slice:

`members(K, audit) = ⋃ { addrs(F) : (a, F, G) ∈ L_K^Σ }`

`targets_of(x, audit) = ⋃ { addrs(G) : (a, F, G) ∈ L_K^Σ ∧ x ∈ addrs(F) }`

`is_K(addr)` at audit ≡ `(∃ (a, F, G) ∈ L_K^Σ :: addr ∈ coverage(F))`

— finite and computable by the same bounds as the active readings (L-fin, AD), and AM-conformant (source arguments matched by denotation, the membership test by coverage). The behavior atoms receive *no* audit reading: BH2's walk "reads the active view, never the audit slice" (ASN-0128), and BH1, BH3, and BH4 are likewise defined against active slices — they are *fixed-view* atoms (PC3), their slice part of their meaning.

**V-TUP (TupleProjections).** QD below admits tuple-valued domains (`A_K`, `L_K`), and a bound tuple needs vocabulary to act on it. For a variable `x` bound to a tuple `(a, F, G)` (the slices are triple-restricted, ASN-0086), we admit:

- `addr(x) : T` — the tuple address;
- `addrs_F(x) : ℘_fin(T)` and `addrs_G(x) : ℘_fin(T)` — the denoted sets of the from- and to-endsets (AD's `addrs(·)`);
- `t ∈ coverage_F(x)` and `t ∈ coverage_G(x)` : `Bool` — coverage-*membership* tests, decidable span-by-span over the finitely many spans (AD): per span `(s, ℓ)`, form the upper bound `s ⊕ ℓ` and compare — TumblerAdd with T2, the pair CoverageEqualityDecidable's procedure names (ASN-0086): span membership is an add-then-compare, never comparison alone. The arithmetic is the test's implementation, inside the leaf; composition sees only the Boolean. Membership only: `coverage(F)` itself is an infinite address set, outside COD, and never a term value.

These are ASN-0128's two argument regimes side by side on one tuple — coverage tests in the membership regime, `addrs` projections in the enumeration regime, each read directly from the stored value. For a fixed binding of `x`, every V-TUP read is constant across states, the stored value being immutable (L12).

**V-PRIM (PrimitiveAdmission).** The *state-independent primitives* are admitted to the vocabulary as degenerate atoms:

- the comparisons on addresses: address equality, the prefix order `≼`, and the total order T1 (ASN-0034) — each Boolean-valued, reading no state; T2 (IntrinsicComparison, ASN-0034) is not a fourth comparison but the computability warrant for equality and T1 — the theorem that both are decided from the two operands alone — with `≼` decided the same way through its finite componentwise definition (Prefix, ASN-0034);
- the finite-set operations on `℘_fin(T)`-valued terms: membership (`t ∈ S`), set equality, and the emptiness test (`S = ∅`) — each a finite enumeration of an already-finite value — and `elems : Seq_fin(T) → ℘_fin(T)`, the order-forgetting projection, count-faithful on `chain`'s output: the returned sequence's elements are pairwise distinct (the walk's are by BH2, and a rewrite only deletes, UV), so `count(elems(chain(t)))` is the returned sequence's length;
- the meta-level ℕ operations: the comparisons (`=`, `≤`) and addition (`+`) on ℕ-valued terms — addition is the operation PC2a's cross-type sums are made of, admitted as vocabulary rather than left ambient;
- the map lookup, per registered class: `·[K] : Map_fin → T ∪ {⊥}` on `Map_fin`-valued terms, `K` entering as an index — a named class or a V-IDX-bound class variable, statically expanded — with the result composing through PC2's binder guard like any verdict; for BH3-attached Binary `K`, `targets_keyed(s)[K] = target_of(s, K)` by BH3's join, an absent key reading ⊥ exactly where `target_of` verdicts ⊥ (ASN-0128);
- constants and literals, one closed form per COD entry that needs one: the Boolean constants `⊤` and `⊥`, ℕ literals (count bounds, `stale`'s horizon), address literals (query data — pattern addresses, query arguments), and the verdict constant `⊥` of each ⊥-adjoined codomain;
- the definedness tests on the ⊥-adjoined codomains: `def : (T ∪ {⊥}) → Bool` and `def : (ℕ ∪ {⊥}) → Bool`, written `· ≠ ⊥` — the conditions of PC2's binder guard. Equality of a defined value against an address or a numeral is reached *through* the binder (`if f(s) is some y then y = c else …`), whose bound `y` carries the narrowed base type (PC2), so no equality operation on a ⊥-adjoined codomain itself is needed, and none is admitted.

They enter terms exactly as atoms do: in Boolean position, in QD filter bodies (the membership and `≼` tests in the worked compositions), and in PC2 chains.

**V-DOC (ResidenceAtom).** The membership atom `is_doc : T → Bool`, with `is_doc(d)` true at Σ iff `d ∈ dom(Σ.M)` — document-residence, the language's one document-store read. Membership only: the atom consults the store domain at its argument and licenses no enumeration — `dom(Σ.M)` is not a QD base. Its ground is the emit surface's own home validation. It enters terms in Boolean position like any membership atom.

**V-STAT (VocabularyStaticity).** `V_atom` is identical at every reachable state. *Proof.* The template families and V-PRIM's per-class lookup family are functions of the registration records alone, and the extended record is constant at every `→_sh*`-reachable state (R1, ASN-0128); the remaining V-TUP, V-PRIM, and V-DOC symbols form fixed sets, independent of registry and state alike. ∎ Registering a new K extends `V_atom` by `Tpl(record(K))` and the lookup `·[K]` (V-PRIM) — at construction only (R-VAL, ASN-0128); no transition changes the vocabulary.

**COD (Codomains).** Atom and composite codomains are drawn from

`Codom = {Bool, T, ℘_fin(T), T ∪ {⊥}, Seq_fin(T), Map_fin, ℕ, ℕ ∪ {⊥}}`

— Boolean, address, finite address set, optional address, finite address sequence, finite map, natural number, optional natural number. `Map_fin`, the one carrier the gloss leaves open, is the finite partial maps from registered coverage classes to `T`. The two base types embed in their ⊥-adjoined companions — `T ⊆ T ∪ {⊥}` and `ℕ ⊆ ℕ ∪ {⊥}`, a base-typed term standing wherever the ⊥-adjoined type is expected — and PC2's binder guard is the only traffic the other way, narrowing a ⊥-adjoined value to its base type behind a definedness test: both directions are operations between listed codomains. PC0–PC2a compose within `Codom` and introduce no codomain beyond it.

**Two argument regimes, atom-level.** The *atoms* observe ASN-0128's AD/AM discipline: membership atoms test coverage (total, decidable), enumeration atoms return denoted addresses and match their arguments per AM (denotation-keyed forward, coverage-keyed reverse). The discipline does not lift to composites: over QD's tuple-valued bases, V-TUP's per-tuple tests express coverage-keyed *forward* matching for every registered K — PC6's `Observe_K` spelling is the canonical instance, its F̂-conjuncts coverage tests on the F slot — and complete *reverse* lookup for every registered K: `⋃({x ∈ A_K : target ∈ coverage_G(x)}, addrs_F)`, a QD filter under a PC2a fold, denotes BH3's `sources_to(target)` with no behavior attached anywhere. AM's keying and BH3's opt-in gating (D4, ASN-0128) are thus conventions about which compositions ship as *named atoms*, not fences the algebra preserves: what BH3 withholds is the atom, never the question. Gregory's implementation draws the same line at zero — its one query mechanism matches every endset by span intersection and answers to-keyed queries for every link from the same symmetrically built index, with no per-type opt-in. What does separate the regimes is direction-specific and proven upstream: for an address-denoting endset, membership is definable from denotation — `t ∈ coverage(e) ⟺ (∃ x ∈ addrs(e) :: x ≼ t)` (PrefixSpanCoverage; the D2 bridge is its atom-level instance) — while coverage determines the denoted set only up to its ≼-minimal elements (I0a's separating pair, ASN-0128), which is why `addrs_F` and `addrs_G` are V-TUP primitives rather than forms derived from the coverage tests.

## Quantification domains

**QD (QuantificationDomains).** The class of *domain expressions* is the least class containing the base expressions

`M_K` (the member set at the term's view: `[M_K]_Σ = members(K, v)` for the view `v` PC3 binds), `A_K` (the active K-slice — view-fixed by name), `L_K` (the audit K-slice — view-fixed by name), `L_dom` (`dom(Σ.L)`), `Reg` (the registered coverage classes)

and closed under two formations:

- *Filtering*: if `D ∈ QD` is address- or tuple-valued (every base but `Reg`) and `P : D × S → Bool` is a Boolean PL predicate, then `{x ∈ D : P(x, ·)} ∈ QD` — a filter body may carry free arguments, making the domain expression *parameterized*; evaluation binds the parameters before interpreting.
- *Set-valued terms*: every `℘_fin(T)`-valued PL term, its parameters bound, is a domain expression denoting its own value — `targets_of(x)`, a PC2a union, an `elems(chain(t))`. Without this closure, aggregation would reach the bases but not the algebra's own set-valued results: "x targets at most n addresses" would be inexpressible while `under_cap` counts sources.

*`Reg` is quantification-only.* Class-variable bodies exist only under PC1's `Reg` binders (V-IDX), and the one variable-free `Reg` position is `count(Reg)` (PC2a), a state-independent constant by R1 and C0. A filter `{K ∈ Reg : P(K)}` or a fold `⋃(Reg, f)` would need a class-variable body outside that scope, and the vocabulary supplies none — V-PRIM admits no class-valued operation, not even class equality — so neither form is in the grammar; cross-type questions are asked the two admitted ways: V-IDX's static expansion for quantified bodies, V-PRIM's `+` over named per-type counts for totals (PC2a). The restriction tracks both authorities: no read operation in Gregory's implementation enumerates, filters, or aggregates over link types — types enter the read path only as caller-supplied selectors or as a named link's own endset value — and Nelson's design never treats the type vocabulary as a queryable domain: it is open-ended, never system-enumerated, a type census being middle-end work over per-type queries.

**QD-refl (TermReflection).** Every *address-valued* domain expression — one whose denotation is a subset of `T`: `M_K`, `L_dom`, a filter over an address-valued domain, and trivially every set-valued term (there reflection is the identity; the reflected `M_K` coincides with the `members` atom) — is itself a `℘_fin(T)`-valued PL term denoting `[D]_Σ`, the typing sound by QD-fin. This is the licensing rule that puts a domain in term position, where V-PRIM's set operations consume it. The address-valued restriction is load-bearing: `A_K` and `L_K` are tuple-valued and `Reg` class-valued — outside `℘_fin(T)`, indeed outside COD — so the tuple-valued slices serve as quantification and fold domains only, never as term values, and `Reg` more narrowly still: quantification and bare `count` (its restriction above). Reflection adds no evaluation form beyond the domain's own interpretation: interpreting the reflected term is interpreting the domain — the domain-interpretation node form PC6's evaluation class names — the same finite enumeration PC1's reduction performs.

**QD-audit (BaseReadAudit).** The vocabulary audit (V) covers `V_atom`; the bases need an audit line of their own, since a domain base grants an enumeration read whether or not any atom names it. Measured against the upstream read surface: `A_K` and `L_K` are `Observe_K`'s two selectable slices (empty patterns enumerate a whole slice, ASN-0086); `M_K` is D1/V-AUD over them (the default reading adds BH1's rewrite, itself an active-slice read); `L_dom` is recoverable without a read of its own, as the union of the audit slices over the registered classes — every stored tuple carries a registered type (P6, ASN-0126, at extended-record states via RP-a, ASN-0128); `Reg` is the constant registry (R1). The document store contributes the membership atom `is_doc` (V-DOC), not a base: document-residence `d ∈ dom(Σ.M)` is the emit surface's own home validation — performed on every `idem = ⊤` miss (I1: home validation is branch-local, a hit never reads `d`), every admitted `idem = ⊥` call (I5), and every `Nullify_Binary` call (P0, both branches, S3 — all ASN-0128) — the one *arrangement-store*-domain test the upstream contracts perform, and a gating discipline written in PL must be able to state what the surface checks. The link store's analogous surface check, `Nullify_Binary`'s P-tgt (S3), is a disjunction — residence, `a ∈ A_rel^Σ`, or self-emit, `a = a_emit(Σ, d_retr)` — and PL states exactly the residence disjunct: that clause needs no atom of its own, being already expressible as membership in the reflected `L_dom`. The self-emit disjunct has no PL spelling — see C-emit (The ceiling). The residence test grounds no more than itself: a `M_dom` base would further license folding and reflecting over the whole document set — `(∀ d ∈ M_dom :: …)`, `count(M_dom)`, the document set in term position — and that enumeration is a read neither authority performs: Gregory's read path consults the document store only as a point lookup against a caller-supplied address, document discovery running through the content-identity index rather than any listing of document keys, and Nelson's design offers no docuverse directory — a document census, like the type census (`Reg`'s restriction above), is middle-end work over the reads the surface does expose. `dom(Σ.C)` has no base and no membership atom (Structural reads only, below).

`QD` and `PL` are defined by mutual induction; the induction is well-founded on syntactic depth. Each `D ∈ QD` denotes at state Σ (and a binding of its parameters) a set `[D]_Σ` by the evident interpretation (`[Reg]_Σ` is state-independent by R1).

**QD-fin (DomainFiniteness).** `[D]_Σ` is finite for every `D ∈ QD` at every reachable Σ. *Proof.* Base case: `dom(Σ.L)` is finite by induction on the reaching derivation — the base is `Σ_init.L = ∅` (R-VAL, ASN-0128); the step, because each K.λ_sh adjoins at most one link key and K.σ and K.α steps leave the link store framed (step effects, GatedTransitionRelation, ASN-0126, as extended by R-TR, ASN-0128). `A_K^Σ ⊆ L_K^Σ` inject into `dom(Σ.L)` via `addr` (R1 AddressInjectivity, ASN-0086), hence are finite; `M_K` is finite by D1's bound and V-AUD's (finitely many tuples by the link-store case just established, finitely many spans per endset, AD); `Reg` is finite by C0 (ASN-0126). Filtering yields subsets; a set-valued term denotes a finite set by its COD typing (each `℘_fin(T)`-valued atom is bounded by AD, and PC2a's `⋃` is a finite union of finite sets). ∎

## The composition primitives

**PC0 (BooleanClosure).** For PL predicates `P, Q : S → Bool`, the pointwise `P ∧ Q`, `P ∨ Q`, `¬P`, `P ⇒ Q`, `P ⇔ Q` are PL predicates of the same signature. Both constituents read the *same* Σ and the same view (PC3). The `S → Bool` functions over fixed Σ form a Boolean algebra under these operations; no further axiomatization is needed.

**PC1 (QuantificationClosure).** For `D ∈ QD` and a PL predicate `P : D × S → Bool`,

`(∀ x ∈ D :: P(x, ·)) : S → Bool`  and  `(∃ x ∈ D :: P(x, ·)) : S → Bool`

are PL predicates: by QD-fin the quantifiers reduce at each Σ to finite conjunctions and disjunctions over `[D]_Σ`, well-defined by PC0. Filtered domains compose freely (a filtered active slice is again in QD), and quantifying over `Reg` expresses cross-type questions no single K's atoms can ask.

**V-IDX (IndexedFamilies).** Quantification over `Reg` binds a *class variable*: in `(∀ K ∈ Reg :: Φ(K))` the body applies atom families at the bound class — `M_K`, `is_K`, `L_K` with `K` a variable — a term former that would otherwise be undefined; PC1's `Reg` binders are the grammar's only class-variable positions. It is defined by *static expansion*: `[Reg]_Σ` is the same finite set at every state (R1, C0, via V-STAT), so the quantified term denotes the finite conjunction (disjunction) of the closed instances `Φ(K₀)`, one per registered class — substitution of named classes into template families, identical at every state. *Well-formedness is instance-wise*: a `Reg`-quantified term is well-formed iff each of its finitely many expansion instances `Φ(K₀)` is a PL term. The vocabulary is non-uniform across `Reg`, and the instance-wise rule resolves the non-uniformity directly: a body applying a *class-indexed* behavior-family atom (`is_filtered`, `succs`, `tip`, `age`, `stale`, …) at the bound class is a PL term only with the behavior attached at *every* registered class, and `R` is mandatory with `behaviors = ∅` (S3, R-C1), so any such `Reg`-body has a non-term `R`-instance and is not in PL. The one non-obvious route to per-class behavior data survives the exclusion: V-PRIM's keyed lookup `targets_keyed(s)[K]` at the bound class reads BH3's verdict — defined at every registered index, absent keys reading ⊥ — without the body ever applying an atom the class may lack. The instance-wise condition remains decidable at construction (the registry is static, V-STAT, so the instance set is fixed with the vocabulary). No new semantic former is introduced; the binder is definitional shorthand, and PC6's tree decomposition sees only the expansion.

**PC2 (ValueComposition).** For a PL term `f : S → C₁` and a *state-indexed* PL term `g : C₁ × S → C₂` with matching types in `Codom`, the composition `s ↦ g(f(s), s) : S → C₂` is a PL term. The outer constituent may itself read state — the `is_retired` of the worked `head_live` below — and both constituents read the *same* Σ and the same view: PC0's provision, extended to value position (the state-independent case `g : C₁ → C₂` is the degenerate instance that ignores its state argument). *Partiality is guarded, never silent*: the ⊥-adjoined codomains `T ∪ {⊥}` and `ℕ ∪ {⊥}` (the `tip`/`target_of` verdicts and `age`'s activeness verdict) compose only through the *binder guard*

`if f(s) is some y then g(y, s) else c_default`

whose condition is V-PRIM's definedness test `def(f(s))`, a PC0 Boolean, and whose binder is the typing rule keyed to that test: in the then-branch, `y` names the defined value at the *narrowed* base type — `T` from `T ∪ {⊥}`, `ℕ` from `ℕ ∪ {⊥}` — so vocabulary typed over the base type (address equality, `≼`, `is_K`, the ℕ comparisons) applies to `y` with no coercion, and no operation on a ⊥-adjoined codomain beyond `def` is ever needed (none is admitted, V-PRIM). The else-branch `c_default` is any PL term of codomain `C₂`, evaluated at the same Σ and view as the rest of the guard — a V-PRIM constant in the common case, a state-reading term equally admitted: for Boolean `C₂` a state-reading else is already PC0-reconstructible (`(def(f) ∧ …) ∨ (¬def(f) ∧ Q)`), and the binder guard being PL's only conditional former, the term reading is what keeps the value codomains (`T`, ℕ) as expressive as the Boolean one. Partiality surfaces as a branch in the term, not as an undefined evaluation. ⊥ is a *verdict*, with meaning fixed by the atom that returns it (a branch, a cycle, multiplicity, inactivity); the guard propagates the verdict, it does not erase it.

**PC2a (AggregationClosure).** For `D ∈ QD`:

- `count(D) = |[D]_Σ| : ℕ`, with V-PRIM's ℕ comparisons in Boolean position and V-PRIM's `+` combining counts — admitted at every `D ∈ QD`, the variable-free `count(Reg)` included (a constant by R1/C0; filtered-`Reg` domains do not exist, QD);
- `max_{T1}(D)` and `min_{T1}(D)` over address-valued domains: the T1-extremum of `[D]_Σ` when non-empty, ⊥ when empty — typed into `T ∪ {⊥}` and composing through PC2's binder guard — well-defined because T1 totally orders tumblers (ASN-0034) and the domain is finite;
- `⋃(D, f) : ℘_fin(T)` for an address- or tuple-valued `D` (`Reg` excluded — quantification-only, QD) and a set-valued PL term `f : D × S → ℘_fin(T)`: the union `⋃_{x ∈ [D]_Σ} f(x, Σ)` — a finite union of finite sets (the `targets_under` recipe's outer operation).

The folds re-enter the algebra: a `℘_fin(T)`-valued fold result is itself a QD domain expression (QD's set-valued closure), so `count(targets_of(x))` and `count(⋃(D, f))` are well-typed — aggregation reaches every set-valued term, not only the bases. All folds are finite, over QD-fin domains — the same reduction PC1 performs with ∧/∨, performed with counting and comparison — so aggregation raises no expressiveness beyond the closure and needs no new evaluation machinery. Two commitments ride on PC2a. *Set semantics, settled*: `count` counts the elements of a domain interpretation — a set of addresses or tuples in the selected view — never occurrences, and the view qualifies every illustrative bound: under `idem = ⊤` on surface-emitted derivations the *active-view* per-I0-class count is at most 1 (I1a, ASN-0128 — a bound on `A_K` alone; the *audit* slice may hold arbitrarily many I0-equal tuples, resurrection re-depositing the same pair at a fresh address by design: I2, ASN-0128, with R6c, ASN-0086), while under `idem = ⊥` the *audit-view* per-I0-class count is the deposit count — the substrate holds the duplicates as distinct tuples — and the active-view count is the deposits less the I0-class's nullified members (retracted later or born nullified, I3, ASN-0128); the algebra itself is everywhere set-valued, and a cross-type composite is a sum of per-type counts taken with V-PRIM's admitted `+` (settling ASN-0128 Open Question 2: cross-type totals are PL terms — per-type set cardinalities combined by meta-level arithmetic, never a new counting mode). *Ordinal extrema, scoped*: `max_{T1}` over link addresses recovers emission order only within one home's chain (the ordinal-time doctrine, BH4, ASN-0128); cross-home T1 comparison is well-defined but temporally meaningless, and any "latest" built from it inherits the per-home scope.

**WT (WellTyping).** The signatures stated former-by-former assemble into a typing judgment, defined here so that decidability is a claim about a defined relation. A *context* Γ assigns each free variable a sort: a codomain `C ∈ Codom` — an address parameter (query data, a filter's free argument, QD) carries `T`; PC2's binder guard binds its variable at the narrowed base type; plain PC2's composition variable carries the inner constituent's codomain `C₁` — or the *tuple sort* `Tup`, for binders over the tuple-valued slices `A_K` and `L_K` (a sort outside COD: a tuple variable is consumed by V-TUP's projections and tests and is never itself a term value, QD-refl). Class variables never enter Γ: a `Reg`-quantified term types through its expansion instances (V-IDX), each closed in the class variable. Two judgments are defined by mutual induction on syntax, the `S` argument elided per the signature convention above: `Γ ⊢ e : C` for terms, `C ∈ Codom`, and `Γ ⊢ D dom(s)` for domain expressions, `s ∈ {T, Tup}` the element sort. One rule per former, each transcribing the signature stated where the former is introduced: a codomain-sorted variable is a term at its context sort; an atom, projection, or primitive types by its stated signature at matching argument sorts (V, V-TUP, V-PRIM, V-DOC — V-PRIM's constants and literals the nullary case); PC0's connectives take `Bool` to `Bool`; PC1 yields `(∀/∃ x ∈ D :: P) : Bool` from `Γ ⊢ D dom(s)` and `Γ, x : s ⊢ P : Bool`; PC2's plain composition is transcribed in context-extension form, like every other binding former — its stated signature `g : C₁ × S → C₂` reads precisely as a term `g` with one free composition variable of sort `C₁`, the `S` argument elided as everywhere — yielding `Γ ⊢ g[x := f] : C₂` from `Γ ⊢ f : C₁` and `Γ, x : C₁ ⊢ g : C₂`, the composite `s ↦ g(f(s), s)` being the substitution instance; its binder guard yields `C₂` from `Γ ⊢ f : C ∪ {⊥}`, `Γ, y : C ⊢ g : C₂`, and `Γ ⊢ c_default : C₂`; PC2a types `count(D) : ℕ`, the T1-extrema at `T ∪ {⊥}` over address-valued domains, and `⋃(D, f) : ℘_fin(T)` from `Γ ⊢ D dom(s)` and `Γ, x : s ⊢ f : ℘_fin(T)`; QD's bases carry fixed sorts (`M_K` and `L_dom` at `dom(T)`, `A_K` and `L_K` at `dom(Tup)`), a filter `{x ∈ D : P}` is at `dom(s)` from `Γ ⊢ D dom(s)` and `Γ, x : s ⊢ P : Bool`, a `℘_fin(T)`-valued term is a domain at `dom(T)` (QD's set-valued closure), and QD-refl types an address-valued domain as a term at `℘_fin(T)`. `Reg` needs no domain sort: its two admitted positions are PC1's binders, typed instance-wise, and the variable-free `count(Reg) : ℕ` (QD's restriction). *Decidability.* The rules are syntax-directed — the node's former selects its one rule — and every premise concerns a strictly smaller phrase: a quantifier's or filter's body, a composition's constituents, and for `Reg` quantification the finitely many expansion instances (C0), each a named-class substitution into the strictly smaller body. Every side condition is a finite match: sorts against the finite `Codom` plus `Tup`, signatures against the finite, state-constant `V_atom` (V-STAT; finite since the registry is, C0). A bottom-up pass over the finite syntax tree therefore decides both judgments, reading no state: well-typing is settled at construction against `Σ_init`'s registry, once for every reachable state. ∎

**PC3 (ViewParametricity).** Every PL term carries one view `v ∈ {audit, active, default}` (the lenses, ASN-0128), fixed at the top level. The view binds the *view-parameterized* constituents: the core-family atoms — `members`, `targets_of`, `is_K` — and the QD base `M_K` read the slice `v` selects (active and default per ASN-0128, audit per V-AUD; `is_K` under default equals its active reading, membership being never rewritten, UV). The *fixed-view* constituents are not rebound: the named slices `A_K` and `L_K` denote the active and audit K-slices at every term view, and the behavior atoms (BH1–BH4) read the active slices their ASN-0128 definitions name — under `v = default` UV's presentation rewrite applies to their collection-valued results, and under `v = audit` they still read active state, their slice being part of their meaning rather than a parameter. There is no author-selectable per-constituent view *parameter* in PL — but this is a convention about atom-name binding, not an expressiveness fence. Cross-view readings are derivable now, inside a term of any view, through the fixed-view slices: `⋃(L_K, addrs_F)` rebuilds `members(K, audit)` within an active-view term (PC2a over V-TUP — it *is* V-AUD's union), `(∃ x ∈ L_K :: t ∈ coverage_F(x))` is the audit `is_K`, and `{x ∈ L_K : P_active(x)}` — an audit-view domain filtered by an active-view body — is a well-formed QD expression whose semantics is already fixed: every constituent reads the same Σ (PC0), the slices being different projections of it, so no coherence condition arises. What PC3 fixes is which slice the view-parameterized *names* — `members`, `targets_of`, `is_K`, `M_K` — denote in a given term; what is deferred (Open Question 1) is first-class surface syntax (`P[v]`) and its pragmatics, not the semantic capability. The D2 bridge (`is_K(addr) ⟺ (∃ x ∈ members(K, active) :: x ≼ addr)` at F-denoting states) is on this account a *lemma relating atoms across views*, not a mixed-view term former.

**UV (UniformDefaultView).** The default view's semantics, given per codomain under one principle: *filtering is presentation — it rewrites collection-valued results elementwise and rewrites nothing else: never verdicts, never arguments, never traversal, never membership, never stored values.* Write `filtered(x)` for `(∃ J ∈ Φ, J ≠ K_queried :: is_filtered_J(x))`, BH1's rewrite predicate (ASN-0128). Under `v = default`:

- *Collections* — the template- and behavior-family enumeration surfaces, `℘_fin(T)`- or `Seq_fin(T)`-valued: `members`, `targets_of`, `succs`, `sources_to`, the sequence `chain` returns, and BH4's `stale` — the result drops exactly the elements `x` with `filtered(x)`. For `chain` this fixes the length a count reads: `count(elems(chain(t)))` (V-PRIM's count-faithful projection) is the walk's length at term views `audit` and `active`, but at `default` the rewritten sequence's length — strictly shorter whenever a traversed element is filtered. The scope is this list, not the codomain: V-TUP's projections are raw stored-value reads at every view, never rewritten — value reads of an in-hand tuple, not result surfaces (nor is `filtered` even defined on them, keyed as it is to a queried class `K_queried` that no bound-tuple projection has). (`stale` is a read; the write surface `retract_stale` is no PL term and consumes the active reading per its ASN-0128 contract, outside UV's scope.)
- *Verdicts and optionals* (`T ∪ {⊥}`, `ℕ ∪ {⊥}`, `Map_fin`): never rewritten (the ⊥ semantics PC2 fixes). `tip` and `target_of` report the active structure's verdict even when the reported address is filtered from every enumeration, `age` reports its count, and `targets_keyed` — a join of `target_of` verdicts — keeps all its keys and values.
- *Booleans*: never rewritten — `is_K` and `is_filtered` (membership atoms), and `is_in_chain` too, which deserves the explicit word because AD classes it as enumeration-*derived*: it is a verdict about the active walk (`target ∈ chain(addr)` evaluated against the unrewritten walk), not a read of the default-view result sequence, so its default-view value equals its active-view value even when the queried element is retired mid-chain.
- *Arguments and traversal*: never filtered — `chain` walks the active denoted graph; a retired mid-chain element is traversed but not shown in the returned sequence.

UV extends ASN-0128's committed collection rule per codomain rather than inventing a second one, on ASN-0128's own ground: filtering is *presentation*, nullification is *state* — a rewrite that altered traversal, membership, or a verdict would let a presentation-layer mark change query topology, exactly the layer confusion the escape-hatch asymmetry exists to prevent (filtering is undone by selecting `active`; topology changes are undone by nothing).

Two ASN-0128 sentences bear directly on this extension; their readings are fixed as follows. BH2 defines `chain`'s returned list *as* the determinate walk and commits: "BH1 filtering does not rewrite the walk." The reading adopted: *the walk* is the traversal and its verdicts — the vertices visited, the stopping classification, and everything computed from them — exactly what UV's clauses above preserve. What the Collections clause rewrites is the returned sequence's default-view *presentation* — the surface Open Question 1 held open. BH1's "Nothing else is rewritten" is scoped by its own colon list — the active-view equations D1–D3 keep their values, the membership predicates are untouched, raw `Observe_K` never filters — and UV preserves every listed item; the behavior surfaces are not on that list.

**PC4 (Purity).** Every PL term is a pure function of `(dom(Σ.M), Σ.L, Σ.registry)`, its arguments, and its view — the registry component constant by R1, the arrangement store entering through its *domain* alone, and the content store not entering at all (the read exclusions of Structural reads only, below, are the premise here) — so a term is a function of the link store, one domain set, and a constant. No memoization, no emission-order dependence, no side effects: atoms and bases evaluate along the base's three read routes — `Observe_K` and the active-subset machinery (ASN-0086) for the slice-reading atoms, the store-domain reads for `L_dom` (enumeration) and `is_doc` (membership), home-chain arithmetic over `dom(Σ.L)`'s homed segments for BH4's `age` and `stale` (FP) — reading state alone; PC0–PC2a and QD-refl's reflected domains preserve purity by induction. Two evaluators of the same term at the same Σ agree: purity makes evaluation a deterministic function of the state. But *that a concurrent observer reads one coherent Σ at all* is the isolation model's to grant, not purity's (ASN-0134), and the discriminator there is access count, not atom count: a term realized as one bounded access — a lone `Observe_K`, an `age` descent — is *snapshot-local*, read against one committed state (A3 SnapshotRead, V0; MIC clause 4) and witnessing no partial step (A4, NoTornStep); a term composing several reads — `OPEN(t)` below reading both the cmt and res slices (the cross-type join ASN-0134 names), a `stale` enumeration — is a *multi-read verdict* (V2), sound about a single Σ exactly when its constituent reads are pinned to one committed index (MIC clause 6's per-verdict reader snapshot; SAFE(d): no multi-read verdict straddles a write). Granted that snapshot, concurrent evaluation is safe and coordination is entirely an emit-side concern; absent it, a composed term's reads may straddle an in-flight `Emit`/`Nullify` and fuse two committed states into one verdict — an isolation obligation PL inherits from the substrate, not one this note's purity discharges.

**PC5 (TerminationOnFiniteSubstrate).** Every PL term's evaluation halts at every reachable state. *Proof sketch.* Atoms terminate by their ASN-0128 bounds (finite enumerations under L-fin/AD; `chain` by BH2's decreasing bound); V-AUD's readings and V-TUP's tests by the same bounds (L-fin, finitely many spans, one TumblerAdd and a bounded pair of T2 comparisons per span); V-PRIM's primitives are finite operations on finite values; `is_doc` is a single membership check on `dom(Σ.M)` (V-DOC). PC0/PC2 are finite trees fixed by syntax; PC1/PC2a reduce to finite folds over QD-fin domains; a QD-refl reflected domain evaluates by the domain's own finite interpretation (QD-fin). ∎ With PC4: every PL predicate is decidable at every reachable state.

## The ceiling

**PC6 (ExpressiveClosure).** Define `PL` as the least class containing `V_atom` and closed under PC0, PC1 (with V-IDX), PC2, PC2a, and QD-refl's term reflection. A ceiling claim is circular until "evaluable" is defined, so we fix its two parameters explicitly — a base and an evaluation class. The *base* is the substrate's read surface *at atom granularity*, enumerable: `Observe_K` (the one surface read on `Σ.L` — empty patterns enumerate a whole slice, so `L_K`, and `A_K` through the active-subset machinery derived from it, are base-enumerable); the template atoms of `V_atom`, each a single base call; an *enumeration* read of the link-store domain `dom(Σ.L)` — enumeration, not membership, because PC1/PC2a fold over it and no membership oracle over the infinite carrier `T` recovers a finite domain's element list (membership tests are the derived case, V-PRIM's `∈` over the enumerated set; the read is `Observe_K`-recoverable — QD-audit's accounting); a *membership* read of the arrangement-store domain (`is_doc`'s residence test, V-DOC; `dom(Σ.C)` has no base read at all, Structural reads only); V-TUP's per-tuple reads of an in-hand tuple's stored value; the registry lookup (constant, R1); and the state-independent primitives (V-PRIM — constants and literals as leaves, operations as nodes). The granularity is the enumeration's load-bearing choice: the machinery *inside* a base call — the span arithmetic that forms `s ⊕ ℓ` and compares (TumblerAdd with T2, CoverageEqualityDecidable's pair, ASN-0086, behind every coverage test and the `nullified` computation), the T4 field extraction behind `home` and the chain arithmetic `inc(·, 0)` behind BH4's `age` (prefix testing is no substitute: `d ≼ a'` does not characterize `home(a') = d`, a link homed at a sub-document of `d` extending `d`'s prefix too) — is consumed behind each call's proven bound and is *not* a composable leaf. Gregory's read path draws the same line: query arguments are compared (`tumblercmp`, `intervalcmp`) and prefix-tested (`tumblertruncate` with `tumblereq`), never operated on — span addition runs inside the traversal (`tumbleradd` forming each crum's reach), increment is allocation-path arithmetic, and a link's home document is read out of the stored record rather than recomputed from its address. The *evaluation class* is *syntax-directed evaluation*: computations whose control structure is a finite tree fixed by the evaluated expression's syntax and traversed once — each node a base call (internal iteration permitted only here, behind the atom's own termination bound: `chain` is a bounded-iteration combinator whose read count is state-dependent under BH2's measure, not a fixed finite read pattern), a combinator from the admitted vocabulary (PC0's connectives, PC2's binder guard, V-PRIM's operations), a *domain interpretation* from QD — filter evaluation, a single-pass select over the already-interpreted base domain with the admitted Boolean body evaluated once per element (per-element Boolean work of its own kind: set-valued, so neither a PC1 quantifier nor one of PC2a's folds), or reflected-domain enumeration, a domain in term position enumerated by its own interpretation (QD-refl; a set-valued term serving as a domain needs no form of its own, its interpretation the identity on the term's already-computed value) — or a single-pass fold over an already-computed finite collection (computed by one of the node's children — a base call or a domain interpretation), drawn — like the combinators — from the admitted vocabulary (PC1's quantifiers, PC2a's aggregates). Iteration *depth* is fixed by syntax — the nesting of folds and filters — while iteration *width* is bounded by the finite collections visited; what the class excludes is *feedback*: control flow that re-drives base reads from the evaluation's own accumulating output (a repeat-until-stable loop), whose depth no syntax fixes. The restriction is the substrate's stance made formal, not a neutral assumption: the substrate evaluates terms of a closed algebra and never executes foreign read-path code (the extension-language commitment), so syntax-directed evaluation is exactly the computation the substrate performs. *Statement: the COD-valued functions computable by syntax-directed evaluation over the base are exactly those the terms of `PL` denote; restricted to Boolean codomain, the predicates so computable are exactly `PL`'s predicates.* *Forward*: structural induction — a PL term's control tree is its syntax tree (PC6a), its leaves are base calls by the base's own enumeration (the atoms at atom granularity, iteration and arithmetic behind their bounds; QD's bases by the enumeration reads; V-TUP's reads and V-PRIM's leaf forms by admission), its formers are the admitted combinators, folds, and domain interpretations — a filtered domain, in quantifier or aggregate position or reflected into term position (QD-refl), evaluates by the filter node form over its base's interpretation — and evaluation is pure and halting (PC4, PC5). *Converse*: a member of the class is by definition a syntax-fixed tree of base-call leaves, admitted combinators, domain interpretations, and single-pass folds — tree shape and node vocabulary are supplied by the class definition, not derived — so what remains to check is the leaves: every base primitive must be PL-expressible, or normalization fails at that leaf. The one non-trivial case is `Observe_K` itself — a call `Observe_K(Σ, F̂, Ĝ, view)` returns its matching set, which is the QD filter

`{x ∈ D_view : (⋀_{t ∈ F̂} t ∈ coverage_F(x)) ∧ (⋀_{t ∈ Ĝ} t ∈ coverage_G(x))}`

with `D_view` the selected slice (`L_K` or `A_K`): the pattern sets are finite query data, so the conjunctions are finite syntax over V-TUP's per-tuple coverage tests, and the filter is itself a computation the class generates — its filter node form over the slice enumeration. This is why V-TUP must be vocabulary: a pattern query is a *per-tuple conjunction* ("some one active tuple's F covers x and its G covers both y₁ and y₂"), and without per-tuple tests it distinguishes states that every atom denotation conflates — the converse would fail at its first leaf. Of the remaining leaves: the atoms, V-TUP's reads, and V-PRIM's primitives are vocabulary by admission, and the admission is load-bearing here: normalization needs a PL spelling per leaf, which an ambient leaf — a bare `⊤`, an undeclared numeral, an unowned definedness test — would lack; the domain enumeration is QD's base — `L_dom` enters term position as a `℘_fin(T)`-valued term by QD-refl, and the slice enumerations are the tuple-valued domains `L_K`, `A_K`, fold domains by QD. A registry lookup is *not*: no PL atom returns registry data — `shape(K)`, a behavior set, registration status — and its discharge is constant-folding rather than admission: the lookup is state-constant (R1), so a computation containing it is extensionally equal to one with the looked-up value inlined — a V-PRIM constant, a branch taken statically, or a `Reg` expansion (V-IDX) — leaving no registry-reading leaf to normalize. So every syntax-directed evaluation normalizes into the grammar: `V_atom` enumerates the leaf forms, QD's bases the domains, and PC0–PC2a with QD's filters and QD-refl's reflected domains the node forms — matching, form for form, the node vocabulary the evaluation class names.

*What the relativization costs, stated plainly.* Three restrictions are load-bearing — the base's atom granularity, the node vocabulary, the control class — and they fail differently when dropped. The *granularity* restriction is what forces the base's stopping point: an exposed arithmetic leaf — `t ⊕ w` on a query argument — has no PL spelling (V-PRIM admits comparisons, never address arithmetic), so the converse's normalization fails at it; the equality could be restored only by paired admission, granting the operation to V-PRIM and the base together so both sides of the equality move at once. The *vocabulary* restriction is benign at the node level: an unadmitted node combinator — ℕ-multiplication over two counts, say — is computable from the base with syntax-fixed control, merely not admitted; the gap is a deliberate omission, closable by V-PRIM-style admission without touching the state-reading base. New *fold forms* are the same axis at a categorically larger grain: admitting arbitrary fold accumulators admits a computation class, not a combinator — an order-dependent fold over a T1-sorted domain is already an arbitrary finite-state pass — so fold gaps are design exclusions, closable only fold-by-fold; the candidate witness that an unrestricted class strictly exceeds PL is the parity of `count(L_dom)` — a one-bit accumulator over the enumerated domain, computable without feedback, with no evident expression in PL's ℕ fragment as V-PRIM ships it: the comparisons (`=`, `≤`) and `+` on ℕ-valued terms, with ℕ literals — term-to-term throughout, so sums of counts compare against sums of counts (`count(D₁) + count(D₂) = count(D₃)` is well-typed; "against literals" is PD0's polarity discipline on the aggregate stability rules, not the vocabulary's bound). V-PRIM's operations do not exhaust PL's ℕ-valued leaves, so the assessment is scoped to where they do: at a *BH4-free registry* — a well-posed scoping, the ceiling being registry-pinned (below) — counts and literals are the only ℕ-valued leaves, so a parity term reaching the count through ℕ-valued subterms would be a Boolean combination of comparisons among sums of counts and literals, and that fragment supplies no halving or modular operator, no ℕ quantifier, and no evident domain expression denoting a half-sized witness — `count(L_dom) = count(D) + count(D)` is the right shape (doubling itself is available, built from V-PRIM's `+`), but nothing in the algebra plausibly constructs a `D` halving `L_dom` exactly at the even states. The ℕ route is not the whole Boolean fragment: PL contains Boolean terms with no ℕ-valued subterm at all — PC1 quantifications over `L_dom` and the slices with V-TUP and V-PRIM bodies (membership, `≼`, the T1 order), filters, reflected-set tests — and a parity term could a priori live in that quantificational fragment, the order-and-membership analogue of the classical first-order parity question. Ruling that route out is an obligation of the same kind C-reach enumerates: an invariance argument exhibiting state families of opposite `count(L_dom)` parity on which every atom denotation, every aggregate comparison, and every order-sensitive composite agree — in the counting-plus-order regime where C-reach's caveats (ii) and (iii) already bar the shortcut citations. The candidate's recorded obligation is both prongs, not the halving-witness gap alone. A registry attaching BH4 anywhere adds the leaf the ℕ-fragment normal form omits: `age`'s narrowed values enter ℕ position through PC2's binder, quantified bodies over `L_dom` included — `(∃ a ∈ L_dom :: age(a) = c ∧ …)` is an admitted Boolean term that is no comparison among sums of counts — and `age` is built from the chain-index arithmetic (`f_d^Σ`) the granularity restriction otherwise fences off, so the age-bearing case is a separate obligation of any proof. The candidate plausibly stands — *conjectured*, not proven (Open Question 6). The *control* restriction is the substantive one: drop it — admit terminating procedures that drive base reads from evaluation-time feedback — and the base provably decides `reach(x, y)`, the denoted graph being finite at every reachable state (L-fin, QD-fin): `R := {x}; repeat R := R ∪ ⋃_{y ∈ R} succs(y) until stable` halts and answers from base reads alone. PC6 asserts the ceiling for syntax-directed evaluation only. The ceiling moves only when the registry does: a new behavior or shape adds atomic forms; no composition does. The vocabulary being construction-pinned (V-STAT), the ceiling is pinned to `Σ_init`'s registry with it, inheriting ASN-0128's registry-evolution fence (its Open Question 7).

**Structural reads only.** What the enumeration *excludes* is as load-bearing as what it includes: no read primitive touches the content store — value or domain — and none dereferences an arrangement binding `Σ.M(d)(v)`. The content-store exclusion is grounded upstream: no contract consults `dom(Σ.C)` — the emit surface checks homes, never content occupancy — and content is reached only through arrangement (V→I) reads, which the arrangement clause just stated bars. PL consumes the structural substrate — the link store and registry, the link domain by enumeration and the membership tests enumeration derives, the arrangement domain by the residence test alone (`is_doc`, V-DOC), address comparison with the span arithmetic confined inside the base's calls (PC6) — never the value mappings: a function testing the bytes at an address, whether any content occupies an I-address, or which content sits at a V-position, is outside PL and outside this note's claims, an agent-time operation rather than a substrate predicate. The exclusion is what PC6's converse leans on (with value reads excluded, the leaf forms are finitely enumerable), and it draws a deliberate layer boundary rather than leaving a gap: arrangement-reading queries are ASN-0127's territory — the `image`/`findlinks_V` algebra over `Σ.M`, with its own transition dynamics (E-MONO, D-NONMONO) — a separate query layer that meets PL only at the substrate both read. The typed-relation predicate language asks what the link store asserts; the content-region algebra asks what a document's arrangement reaches; neither subsumes the other, by design.

**PC6a (FixpointExclusion).** PL contains no fixed-point or recursion operator: every former PC0–PC2a admits is non-recursive (QD-refl likewise — a typing rule, not a recursion), so a PL term's composition tree is fixed by its syntax, independent of Σ — atoms' internal iteration contributes a leaf, not an unrolling (bounded per PC6's evaluation class). This is a fact about the grammar, and it is all PC6a claims.

**C-reach (ReachInexpressibility — conjecture).** *No PL term computes `reach(x, y)` — transitive closure over the denoted graph — at every reachable state.* Status: **conjecture**, deliberately not a theorem. A proof cannot proceed by citing the inexpressibility of transitive closure in fixed-quantifier-depth first-order logic over finite structures — that route is unsound for PL as actually defined, on three counts. (i) The walk atoms traverse unboundedly at fixed syntax: on states whose denoted K-graph has out-degree ≤ 1 throughout, `is_in_chain(x, y)` *is* `reach(x, y)` at arbitrary distance — "chains longer than the term can traverse" is no general principle, and a lower bound must be fought on *branchy* graph families, where the determinate walk halts (BH2) and the walk atoms go blind. (ii) PC2a's counting exceeds plain first-order logic — Ehrenfeucht–Fraïssé arguments for FO do not handle cardinality comparison. (iii) V-PRIM builds total orders (T1, `≼`) into every structure, and locality-based lower bounds for counting logics degrade over ordered structures. A genuine proof must therefore exhibit branchy, cardinality-balanced state families on which every atom denotation, every aggregate, and every order-sensitive composite agree while `reach` differs — an invariance argument in a counting-plus-order regime where nearby questions are open. We conjecture the exclusion holds — nothing in the algebra plausibly reconstructs closure across branches — and we record the proof obligation as Open Question 6 rather than discharge it by citation. What stands without it: PL *ships* no closure operator (PC6a, a grammar fact); ASN-0128's withholding of multi-hop traversal ("both authorities place multi-hop traversal outside the system") remains the design stance it was — made precise here, not promoted to a theorem; closure, like the mutually-recursive predicate definitions ("settled iff every dependency is settled") PC6a equally bars, is computed at agent time — iterate `succs`, unroll the recursion — and the substrate cannot be handed the loop (the extension that would change this is Open Question 4's). Last, the conjecture's polarity against PC6's control restriction: feedback evaluation over the base decides `reach` (PC6's loop), so a feedback-ceiling claim — that feedback computation denotes exactly what PL terms do — would entail ¬C-reach; conjecturing C-reach is conjecturing that ceiling fails. The converse is no implication: `reach ∈ PL` would leave PC6's parity candidate standing, a vocabulary-axis escape independent of `reach`.

**C-emit (SelfEmitInexpressibility — conjecture).** *No PL term computes the self-emit test `a = a_emit(Σ, d)` — "is `a` the address the next emission homed at `d` would receive" — at every reachable state.* The test is `Nullify_Binary`'s P-tgt self-emit disjunct (S3, ASN-0128), the one clause of the upstream surface checks PL leaves unstated (QD-audit). The baseline is a grammar fact, read off V: the vocabulary supplies no term *spelling* the test — `a_emit(Σ, d) = chain_d(f_d^Σ)` (FrontierUnification, ASN-0126) reads the frontier of the home's chain, an emit-side quantity assembled from the homed-set (`home(a') = d`, which no atom exposes and prefix testing cannot characterize — PC6's granularity discussion) and the chain arithmetic `inc(·, 0)` that V-PRIM excludes — so no direct spelling exists in the grammar. Status: **conjecture**, for the same reason C-reach is one: the grammar fact blocks only the direct spelling, and whether some extensionally equal term computes the test anyway is an invariance question. A proof must be an invariance argument over every atom denotation, handling in particular the two frontier-derived routes the vocabulary *does* admit: BH4's `age` is defined from the very quantity `f_d^Σ` (its home-wide footprint recorded at FP), its narrowed values entering ℕ position through PC2's binder guard wherever BH4 is attached; and the link-domain data of which `a_emit(Σ, d)` is a function enters term position through the reflected `L_dom` (QD-refl). We conjecture neither route closes the gap — `age` reads chain indices relative to the frontier, never the frontier slot's address, and `L_dom` delivers the homed-set only as an undifferentiated subset of the link domain, with no atom to regroup it by home — and we record the proof obligation as Open Question 6, alongside C-reach's. What stands without the conjecture is the design conclusion, which needs only the grammar fact: the gate states P-tgt's residence disjunct (QD-audit), and the self-emit check belongs to the emitting surface, which performs it (S3).

## Predicate dynamics

PC4 and PC5 govern one evaluation at one state. A protocol author needs one more thing the language itself cannot say: how a term's truth behaves *across* `→_sh` steps — whether a trigger can be un-triggered, whether a termination condition, once reached, stays reached. PL deliberately has no temporal operators (PC6), so the dynamics live here as a syntactic classification of terms certifying their behavior along transitions (the classes are spelling-level, PD0), each class grounded in the step effects and frames already proven upstream (the step kinds and their frames: GatedTransitionRelation, ASN-0126, over extended-record states by R-TR, ASN-0128).

**FP (ReadFootprints).** The *footprint* of an atom — the state its evaluation consults — is read off the definitions, and the dynamics classes below are footprint facts:

- core atoms of K at view `audit`: `L_K` (V-AUD);
- core atoms of K at view `active`: `L_K` and `L_R` — the active slice is the audit slice minus `nullified(Σ)`, and `nullified` is computed from the retraction audit slice (ASN-0086);
- `is_filtered` of a BH1 type J: `L_J` and `L_R` (an active-view read, ASN-0128);
- BH2 and BH3 atoms of K: `L_K` and `L_R` (active-view reads, ASN-0128) — except `targets_keyed`, whose footprint is cross-type by construction: it joins `target_of` across *every* BH3-attached Binary type (BH3, ASN-0128), so it reads `⋃ {L_J : J Binary with BH3 attached} ∪ L_R`, indexed by no single K;
- BH4 atoms of K: `L_K`, `L_R`, *and the homed segments of `dom(Σ.L)`* — `age(a) = f_d^Σ − 1 − j` at `d = home(a)` is arithmetic on the home's full chain, and "the chain interleaves every type homed at d" (BH4, ASN-0128): the frontier counts deposits of every type, so the footprint is home-wide, not slice-local;
- *the default-view increment*: under `v = default`, each atom on UV's Collections list — `members`, `targets_of`, `succs`, `sources_to`, `chain`, `stale` — has as its footprint its active-view footprint plus, for each BH1 type J, the footprint of `is_filtered_J` (`L_J` and `L_R`): UV's rewrite is elementwise, and computing it evaluates `is_filtered_J` at each result element. Every other atom — the verdict-, Boolean-, and `Map_fin`-valued (`is_K`, `is_filtered`, `is_in_chain`, `tip`, `target_of`, `targets_keyed`, `age`) and V-TUP's projections (raw stored-value reads at every view, UV) — takes no increment: UV rewrites none of them, so each one's default-view footprint equals its active-view footprint;
- `is_doc`: `dom(Σ.M)` — membership at its argument, the language's one document-store read (V-DOC);
- the bases: `L_dom` reads `dom(Σ.L)` whole; `M_K`, `A_K`, `L_K` read the corresponding core footprints; `Reg` reads the constant registry; V-PRIM reads nothing; V-TUP reads the bound tuple's stored value.

A term's footprint is the union over its atoms and domain expressions.

**PD0 (AuditMonotonicity).** The monotone classes, defined inductively with explicit polarity — the polarity discipline is what keeps wrong-way aggregate tests out. The classes are *spelling-level*: the rules read a term's syntax, not its denotation, so extensionally equal spellings can classify differently — the quantified forms are the certified ones, and an atom whose *definition* is a certified spelling receives its verdict by explicit clause (the audit-membership and reflected-set rules below), not by semantic closure. Call a domain expression *grow-only* iff it is `L_K` or `L_dom` — each only ever extended along `→_sh` (the step effects extend exactly one store at a fresh key and frame the rest: GatedTransitionRelation, ASN-0126, by R-TR, ASN-0128; per-type slice growth is R3, ASN-0086, carried across extended-record steps by ASN-0126's B2 with RP-b, ASN-0128) — or `M_K` in an audit-view term (V-AUD's union over the growing `L_K`), or a filter `{x ∈ D : P(x, ·)}` with `D` grow-only and `P(x, ·) ∈ ST` for every binding, or a *step-constant domain* — a set-valued term reading no state beyond its bound parameters (the sense of the step-constants clause below): V-TUP's `addrs_F(x)` and `addrs_G(x)` of a bound tuple, their stored values immutable (L12, via B2 with RP-b) — constancy being the degenerate case of growth, the set contained in itself at every successor. Two derived set-valued forms receive the grow-only verdict by the same definition-spelling method as the audit-membership clause below: `targets_of(x, audit)` with its argument a literal or an already-bound address — V-AUD spells it as a union over the grow-only `L_K` of step-constant V-TUP projections — and a fold `⋃(D, f)` with `D` grow-only and `f` step-constant per binding: growth adds contributions and rewrites none. Define `ST` (the ⊤-stable forms) and `SF` (the ⊥-stable forms) by mutual induction:

- *Step-constants* — in `ST ∩ SF`: terms reading no state beyond already-bound values — V-PRIM primitives and constants over literals and bound addresses, and V-TUP reads of a bound tuple (the stored value immutable: L12, carried by B2 with RP-b). Once binders fix their arguments, these evaluate identically at every successor state.
- *Residence*: `is_doc(d)` — its argument a literal or an already-bound address — is in `ST`: `dom(Σ.M)` only ever extends along `→_sh` (a K.σ step adjoins one fresh document key; every other step kind frames the arrangement store), so a true residence test stays true. It is not in `SF`: a false test flips on the K.σ that registers `d`.
- *Audit membership*: `is_K(addr)` at view `audit` — its argument a literal or an already-bound address — is in `ST`: V-AUD defines it as an existential over the grow-only `L_K` with a step-constant V-TUP body, so the quantifier rule applies through the definition. It is not in `SF`: a false test flips on a K-deposit whose F-coverage contains the argument.
- *Reflected-set tests*: for a grow-only address-valued domain `D` in term position (QD-refl) and `t` a literal or an already-bound address, the membership test `t ∈ D` is in `ST` and the emptiness test `D = ∅` is in `SF` — growth never removes the member that made the test true and never empties a non-empty denotation. These grant the V-PRIM forms the verdicts their quantified spellings — `(∃ x ∈ D :: x = t)`, `¬(∃ x ∈ D :: ⊤)` — already receive from the quantifier and negation rules.
- *Boolean nodes*: `∧` and `∨` preserve `ST` and preserve `SF`; `¬` swaps `ST` and `SF`; derived connectives classify through their definitions (`P ⇒ Q ∈ ST` when `P ∈ SF` and `Q ∈ ST`).
- *Quantifiers*: `(∃ x ∈ D :: P) ∈ ST` when `D` is grow-only and `P(x, ·) ∈ ST`; `(∀ x ∈ D :: P) ∈ SF` when `D` is grow-only and `P(x, ·) ∈ SF`. Over a *step-constant* `D` both quantifiers preserve both classes — the index set is fixed, so the quantifier is at every state the same finite conjunction (disjunction), classified by the Boolean rules: additionally `(∀ x ∈ D :: P) ∈ ST` when `P(x, ·) ∈ ST`, and `(∃ x ∈ D :: P) ∈ SF` when `P(x, ·) ∈ SF`. The step-constant clauses are what let an audit term quantify *through* a bound tuple's endsets: `(∃ tup ∈ L_K :: t ∈ addrs_F(tup) ∧ (∃ y ∈ addrs_G(tup) :: is_K'(y)))` — some K-tuple from `t` has a target that was ever a K'-member, the inner `is_K'` at view audit — classifies `ST`: the outer existential over the grow-only `L_K`, the inner over the step-constant `addrs_G(tup)`, the body by the audit-membership clause.
- *Aggregates*, over grow-only `D`, against ℕ literals: `count(D) ≥ c ∈ ST` and `count(D) ≤ c ∈ SF`. (Over a *step-constant* `D` the count reads no state beyond the bound parameters, so every comparison against it — equality included — is a step-constant in `ST ∩ SF` by the first clause; the verdicts here and the classification next are for the genuinely growing bases.) Each inequality is in exactly one class; only equality is in neither. `count(D) ≤ c` is in `SF` alone: `count(L_K) ≤ 3` is the canonical non-member of `ST` — true while the slice is small, flipped ⊤→⊥ for good by the fourth K-deposit, exactly the flip `SF` licenses — and dually `count(D) ≥ c` is in `ST` alone, its ⊥→⊤ flip on growth being the direction `SF` forbids. `count(D) = c` lives nowhere: falsified upward from below, it can become true; overshot, never again. T1-extrema are excluded from both classes: the ⊥-at-empty verdict and the extremum's movement under growth make their polarity conditional.

*Statement.* Every `ST` term is *⊤-stable*: once true at a reachable Σ, true at every `→_sh*`-successor. Dually, every `SF` term is *⊥-stable*: once false, false forever. *Ground*, by induction on the rules: a grow-only domain's denotation at Σ is contained in its denotation at every successor (bases by the step effects; audit `M_K` because a union over a growing index set grows; filters because membership persists — the element stays in the base by growth, and its `ST` body stays true by the induction hypothesis; step-constant domains trivially — a constant set is contained in itself; audit `targets_of` and the certified folds because a union over a growing index set of per-binding-fixed contributions grows); no step removes a link address or rewrites a stored value (L12a per step and L12, both carried across extended-record steps by ASN-0126's B2 with RP-b, ASN-0128), so an existential witness persists with its content intact; a universal counterexample never leaves its domain; a quantifier over a step-constant domain is at every state the same finite Boolean combination of its instance bodies, so the Boolean rules carry it; a count over a growing set never decreases, so satisfied lower bounds persist and violated upper bounds stay violated; the Boolean rules are immediate. ∎ "Has this ever happened" is the monotone question; "has nothing of this kind ever happened" is its anti-monotone dual; neither oscillates.

**PD1 (ActiveNonMonotonicity).** Active-view and default-view terms are stable in neither direction, and the perturbations are different in kind. *Active:* `(∃ x ∈ M_K :: P(x))` at view `active` flips ⊥→⊤ on a K-deposit and ⊤→⊥ on a retraction whose target carries the last witness — `Nullify_Binary` removes the tuple from `A_K^Σ` while `L_K^Σ` keeps it. A fire-until-Q loop whose Q is an active-view term can therefore *un-terminate*: Q true at Σ, false again at a successor, with no monotone measure in the language to forbid the oscillation — the worked composition's closing trace computes exactly this flip sequence (⊥→⊤→⊥ on `quiescent(t)` across Σ₁–Σ₃). *Default:* the same term at view `default` additionally flips on a bare BH1-type emission — `retired` deposited on a witnessing address removes it from every default-view enumeration (UV) with the queried type's own tuples untouched: presentation movement changes trigger truth. A protocol that wants a stable gate over active state must either supply the stability *outside* the language (an operating discipline under which the falsifying steps cannot occur — the move DR makes for C3, ASN-0128) or anchor on PD0's audit class instead.

**PD2 (FrameStability).** Per-step invariance, read off the frames and FP's footprints. Every PL term is invariant under every K.α step: no footprint reaches `dom(Σ.C)` (FP — QD-audit admits no content base), and K.α frames everything a footprint can name, so content deposits never move a predicate. A term whose footprint excludes `dom(Σ.M)` is invariant under every K.σ step: each step kind frames every component outside its one extended store (frame clauses, ASN-0126), so every atomic query in the term evaluates against identical components — `is_doc` buys document-residence at the price of K.σ-sensitivity. Sharper, per type, for terms whose domains are per-type slices (not `L_dom`, whose footprint is the whole link domain): for any set 𝒦 of registered coverage classes, a term reading only *audit* slices of types in 𝒦 is invariant under every deposit of a type outside 𝒦 — the deposit grows its own slice and nothing else the term reads. The active-view refinement must respect the *two* cross-type effects the substrate has, plus one cross-type *footprint* a single atom carries. First, retraction: an R-deposit nullifies addresses of any type and can shrink any active slice (the same cross-effect I1a's induction handles, ASN-0128), so the clause requires `[R]` off the depositing side. Second, home-chain arithmetic: BH4's footprint is home-wide (FP) — a deposit of *any* type homed at a document carrying one of K's active tuples advances that home's frontier `f_d`, increments `age` at every K-tuple homed there, and can flip a `stale`-built term with no retraction anywhere ("the chain interleaves every type homed at d", BH4, ASN-0128). Third, the atom-side exception: `targets_keyed`'s footprint is cross-type by construction (FP), so a term containing it reads every BH3-attached Binary type's active slice whatever 𝒦 names. So the active clause reads: a *BH4-free, `targets_keyed`-free* term reading active slices of types in 𝒦 is invariant under deposits of types outside 𝒦 with `[R]` not on the depositing side; a term containing BH4 atoms is additionally perturbed by same-home traffic of every type; and a term containing `targets_keyed`, by deposits of every BH3-attached Binary type. (A default-view term adds, through each UV-rewritten collection atom it contains, every BH1 type's active slice to its footprint — FP's default-view increment — so its non-interference set shrinks by Φ as well.) PD2 is the protocol author's non-interference tool: a trigger built from audit slices of its own types is untouched by every unrelated fire, exactly; a trigger over active slices is untouched by unrelated fires *except retractions, same-home deposits of any type when BH4 atoms appear, and deposits of any BH3-attached Binary type when `targets_keyed` appears*. Name the exceptions or be surprised by them.

The three classes compose with the algebra in the expected way — PC0's `∧` of two ⊤-stable terms is ⊤-stable, `¬` swaps PD0's classes, PC1 over a grow-only domain preserves ∃-stability and breaks ∀-stability — and the classification is the load-bearing input to any termination argument built over this substrate.

## Worked composition

Fix two illustrative app classes alongside ASN-0128's shipped three: `cmt` — Binary, idem=⊥, a comment from a finding address to a target address — and `res` — Binary, idem=⊤, a resolution from a target back to a comment. (These are illustrative registrations exercising the algebra, not standard registrations.)

*The filtered domain.* The open comments on target `t` — the whole term at view `active` (PC3: the view is written once, at the top level, not per atom):

`OPEN(t) = {c ∈ M_cmt : t ∈ targets_of_cmt(c) ∧ ¬(∃ r ∈ M_res :: c ∈ targets_of_res(r))}`

— a QD filter over the base domain `M_cmt`, whose filter body is PC0 over a V-PRIM membership test, an enumeration atom, and a PC1 existential.

*Quiescence-shaped predicate.* `quiescent(t) ≡ OPEN(t) = ∅` — V-PRIM's emptiness test over the reflected domain (QD-refl licenses the address-valued `OPEN(t)` in term position) — equivalently `count(OPEN(t)) = 0` (PC2a) or `¬(∃ c ∈ OPEN(t) :: ⊤)` (PC1, the body V-PRIM's Boolean constant): one composite, three equivalent spellings, all in PL with signature `T → Bool`. Evaluated against `active`; the same term at view `audit` reads the V-AUD slices and asks "was every comment ever resolved at some point recorded" — a different and rarely wanted question, which is why the view is fixed per term (PC3).

*Aggregation with a cap.* `under_cap(t, n) ≡ count({c ∈ M_cmt : t ∈ targets_of_cmt(c)}) ≤ n` — count and meta-comparison against the literal `n` (PC2a, V-PRIM); the operator pattern for any bounded-cycles discipline. The dual direction is equally available, now that set-valued terms are domains: `out_capped(c, n) ≡ count(targets_of_cmt(c)) ≤ n` — "c targets at most n addresses" — counts an enumeration atom's result directly (QD's set-valued closure).

*Value composition through a verdict.* "t's current head is unretired": with `supersedes` shipped (S2, ASN-0128) and BH2 attached,

`head_live(t) ≡ if tip(t) is some h then ¬is_retired(h) else ⊥`

— PC2's binder guard through the `T ∪ {⊥}` codomain: the condition is V-PRIM's definedness test, the binder `h` carries the narrowed type `T`, and the outer constituent `is_retired` — a state-indexed read evaluated at the same Σ and view (PC2) — applies to `h` with no coercion; the else-branch is instantiated at V-PRIM's Boolean constant `⊥`: a branch or cycle at `t` is a *verdict*, and reading it as not-live is this term's explicit decision — the decision point PC2's guard retains for every author in place of an undefined value inherited silently.

*A derived recipe as a PL term.* ASN-0128's `targets_under(addr)` — "an app-side composition rather than a fourth shipped predicate" — is exactly

`targets_under(addr) = ⋃ {targets_of(x) : x ∈ {y ∈ M_K : y ≼ addr}}`

(at view `active`) — a PC2a finite union over a QD filter whose body is the componentwise prefix test (V-PRIM): the algebra is where ASN-0128's recipe lives.

*Cross-type universal.* "every registered class's active slice is non-empty somewhere under d" — `(∀ K ∈ Reg :: (∃ x ∈ M_K :: d ≼ x))` at view `active` — the `Reg`-quantification no single type's atoms express, denoting its static expansion over the registered classes (PC1 with V-IDX). (The body is core-family-only, so V-IDX's instance-wise condition holds at every registry.)

*The trace — the dynamics evaluated at concrete states.* The registrations above — joined at the last step by `retired`, the shipped BH1 designate (S1, ASN-0128) — make PD1's warnings, the active-view flip and the default-view presentation flip both, a four-step computation rather than a description, and put UV's rewrite/preservation split on concrete state. Start from a reachable Σ₀ with one document `d ∈ dom(Σ₀.M)` (one K.σ step from `Σ_init`) and an empty link store (`dom(Σ₀.L) = ∅`: `Σ_init.L = ∅` by R-VAL, and K.σ frames `Σ.L`); fix two distinct query addresses `c₁` (a comment) and `t` (its target). Every emission below is homed at `d`, so the deposits land in order on `d`'s chain — `a₁ = chain_d(0)`, `a₂ = chain_d(1)`, `a₃ = chain_d(2)`, `a₄ = chain_d(3)` (frontier-landing, FrontierUnification, ASN-0126, at extended-record states via RP-a, ASN-0128). Evaluate the headline term at Σ₀ before anything fires, view `active`: `M_cmt = ∅` over the empty store, so `OPEN(t) = ∅` and `quiescent(t) = ⊤` — *vacuously*: quiescence-shaped predicates are true at the empty store, so a fire-until-`quiescent(t)` loop observing Σ₀ terminates before any comment exists, and a sound termination gate needs an activity witness alongside the quiescence term (the audit companion `ever_res` below is one: it evaluates ⊥ at Σ₀).

- *Σ₀ →_sh Σ₁* by `Emit_cmt(Σ₀, d, {c₁}, {t})`: idem=⊥, so no dedup runs and the admitted call deposits (I5); the gate passes (cmt registered Binary, `|F| = |G| = 1`); the deposit `(enc{c₁}, enc{t}, cmt)` lands at `a₁`, active (C2: cmt ≁ R; C3: `L_R^{Σ₀} = ∅`). Evaluating at Σ₁, view `active`: `M_cmt = {c₁}` and `targets_of_cmt(c₁) = {t}`, so the body's membership conjunct holds at `c₁`; `A_res^{Σ₁} = ∅` gives `M_res = ∅`, so the inner existential reduces over the empty domain to ⊥ (PC1) and its negation to ⊤. `OPEN(t) = {c₁}`; `quiescent(t) = ⊥`.
- *Σ₁ →_sh Σ₂* by `Emit_res(Σ₁, d, {t}, {c₁})`: idem=⊤, and the dedup check consults `A_res^{Σ₁} = ∅` — a miss (I1), so the deposit `(enc{t}, enc{c₁}, res)` lands at `a₂`, active (`L_R^{Σ₁}` still empty). Evaluating at Σ₂: `M_res = {t}` and `targets_of_res(t) = {c₁}`, so the inner existential finds its witness `r = t` and the negated conjunct fails at `c₁` — the filter retains nothing. `OPEN(t) = ∅`; `quiescent(t) = ⊤`.
- *Σ₂ →_sh Σ₃* by `Nullify_Binary(Σ₂, d, a₂)`: P0 (`d ∈ dom(Σ.M)`), P-reg ([R] registered Binary, S3, ASN-0128), and P-tgt (`a₂ ∈ A_rel^{Σ₂}`) all hold; the retraction triple lands at `a₃`, and `a₂ ∈ nullified(Σ₃)` with single-tuple scope — `{u : a₂ ≼ u} ∩ A_rel^{Σ₃} = {a₂}` — so `a₁` stays active. Evaluating at Σ₃: the res tuple persists in `L_res^{Σ₃}` but is gone from `A_res^{Σ₃}`, so `M_res = ∅` — the inner existential has lost its only witness — while `M_cmt = {c₁}` still. `OPEN(t) = {c₁}`; `quiescent(t) = ⊥`.
- *Σ₃ →_sh Σ₄* by `Emit_retired(Σ₃, d, {c₁}, ∅)`: the gate passes (`retired` registered Unary, S1, ASN-0128: `|F| = 1`, `G = ∅`); idem=⊤, and the dedup check consults `A_retired^{Σ₃} = ∅` — a miss (I1) — so the deposit `(enc{c₁}, ∅, retired)` lands at `a₄`, active (C2: `retired ≁ R`, R-C1; C3 by DR — the derivation is surface-disciplined, its one `L_R`-growing step being the `Nullify_Binary` above; concretely, the lone retraction's to-coverage `subtree(a₂)` misses the fresh `a₄`, R0a at the post-state). Evaluating at Σ₄, where Φ = {retired} and `is_filtered_retired(c₁) = ⊤` (the active retired tuple's F-coverage `subtree(c₁)` contains `c₁`): under `v = default` the collection atom rewrites — `members(cmt, default) = ∅`, its lone element dropped — while the Boolean atom is preserved — `is_cmt(c₁) = ⊤` still, the membership test reading the untouched active cmt slice (UV: collections rewritten, Booleans never). One atom rewritten, one preserved, at one state: UV's split exhibited. The composite follows its collection base: `quiescent(t)` evaluates ⊤ at view `default` — `M_cmt` reads the rewritten member set, emptying `OPEN(t)` — and ⊥ at view `active`, where `OPEN(t) = {c₁}` persists from Σ₃ (`a₂` stays nullified, R6a). A bare `retired` deposit, no cmt or res tuple touched, flipped the default-view gate and left the active-view reading fixed — FP's default-view footprint increment and PD1's presentation-movement flip, computed.

The value sequence of `quiescent(t)` at view `active` along Σ₀–Σ₄ is ⊤, ⊥, ⊤, ⊥, ⊥ — the vacuous ⊤ at the empty store, then PD1's flip sequence computed on the named term: a fire-until-`quiescent(t)` loop that observed Σ₂ has terminated against a condition Σ₃ falsifies, with no link ever leaving the store — while at view `default` it runs ⊤, ⊥, ⊤, ⊥, ⊤, the last flip made by presentation alone. The audit companion locks instead: `ever_res ≡ (∃ x ∈ L_res :: ⊤)` is a PD0 `ST` term — an existential over the grow-only `L_res` with step-constant body — and evaluates ⊥ at Σ₀ and Σ₁ and ⊤ at Σ₂, Σ₃, and Σ₄: the retraction removed nothing from the audit slice, whose witness persists with its value intact (L12a and L12, carried across extended-record steps by B2 with RP-b). One trace, all three lenses: the active-view gate oscillates, the default-view gate moves on presentation marks the active view ignores, and the audit-view record locks.

## What this note doesn't cover

- **Protocol constructions.** Triggers paired with write operations, termination conditions and their convergence arguments, re-opening rules, and scheduler disciplines (fairness, fire atomicity, non-interference) are application-layer machinery *written in* PL and *typed by* PD0–PD2, but not part of the predicate foundation: this note supplies the language, its evaluation guarantees, and its dynamics; what is built from them is the builder's.
- **Range-valued predicate atoms.** Inherited from ASN-0128: the surface is address-denoting; a predicate layer over span extents is deferred with it.
- **Normal forms.** Whether PL-modulo-extensional-equivalence admits a normal form, and an effective procedure deciding extensional equivalence of terms, are open theory (Open question 3); well-typing is decidable (WT).

## Open questions

1. **First-class views.** Should the view become a first-class parameter (`P[v]`) with per-constituent binding, and which mixed-view idioms deserve named, checkable syntax rather than slice-level reconstruction? (The semantic capability is settled: PC3.)

2. **Existential-witness domains.** QD is base-plus-filter. Domains defined by witness extraction — "the set of x such that some y witnesses P(x, y)" — are expressible only by flattening the witness into PC1's quantifier prefix. Is the flattening always possible within PL, or are there meta-expressible domains PL cannot construct?

3. **Extensional normal form.** Is there an effective procedure deciding whether two PL terms denote the same predicate at every reachable state? Syntactic identity is trivially decidable; extensional equivalence over the reachable-state class is the open half.

4. **The fixpoint successor.** If a forcing case arrives — a protocol whose gating genuinely needs dependency-chain walking rather than agent-time unrolling — the extension is a bounded least-fixed-point operator with an explicit termination measure. What measure discipline keeps PC5 for such an operator?

5. **Deciding the dynamics class.** PD0–PD2 classify by syntactic criteria (view, polarity, domains read). Is class membership decidable for arbitrary PL terms — in particular, is there an effective syntactic check that soundly (if incompletely) certifies ⊤-stability for terms mixing views or polarities, so that a protocol checker can validate a termination condition mechanically?

6. **The inexpressibility conjectures.** What invariance arguments would prove the three conjectures this note records — C-reach, PC6's parity candidate, and C-emit?
