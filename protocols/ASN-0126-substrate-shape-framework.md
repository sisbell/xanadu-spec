# ASN-0126: Substrate Shape Framework

*Narrowing the typed-relation framework into a concrete vocabulary apps register against*

ASN-0086 commits the substrate to typed relations of arity three over `(F, G, K)` and provides the operational vocabulary `Emit_K`, `Observe`, `Nullify`. It does not narrow the cardinalities of the F and G slots, nor does it say anything about what an app must look like when it registers a type. Apps interacting with the substrate need more than ASN-0086 gives. This note adds three things: a finite shape catalog their types are checked against, a static shape-conformance gate the substrate applies at every emit, and an immutable registry whose contents do not drift across states.

## Single-source

Every typed relation the framework gates has a single-span source: `|F| = 1`, where for an endset `e` we write `|e|` for its *span count* — since `Endset = 𝒫_fin(Span)` (ASN-0043), `|e|` is the cardinality of `e` as a finite set of spans. The one F span may itself cover a contiguous range or a whole subtree, not merely one address. In particular `F = ∅` has `|F| = 0`: the rule admits no empty-from source. At the other extreme every multi-span source `|F| ≥ 2` is excluded: a single span covers a *contiguous* T1-interval `{t : s ≤ t < s ⊕ ℓ}` (by the `coverage` definition, ASN-0043, and the T1 ordering, ASN-0034), so the one F span, whatever its reach, is always connected.

## Three shapes by G span count

With F fixed at one span, the framework varies only by what G can hold. We measure G by its span count `|G|`. The framework provides three registrable shapes, parameterized by `|G|`:

| Shape  | G span count   | What it expresses                                              |
|--------|----------------|-----------------------------------------------------------------|
| Unary  | `\|G\| = 0` (G = ∅) | A predicate or marker on a single source                    |
| Binary | `\|G\| = 1`      | A directed relation to one target span                          |
| Multi  | `\|G\|` finite   | A single source connected to finitely many — possibly zero — target spans |

Unary (`|G| = 0`) and Binary (`|G| = 1`) are mutually exclusive; the shapes classify *registrations*, not tuples: a type K is registered once with one shape, and that shape fixes which tuples are well-formed under K.

## The registry

ASN-0043/0086 carry substrate state `Σ = (Σ.C, Σ.M, Σ.L)`. This framework extends that tuple with a fourth, immutable component, the *registry*:

`Σ = (Σ.C, Σ.M, Σ.L, Σ.registry)`

The registry records, for each type an app declares, the shape its tuples must take. It is a partial function `T_admissible/~ ⇀ shape`: a key is a coverage class `[K_j]`, stored concretely as a representative `K_j ∈ T_admissible` against which CoverageEqualityDecidable (ASN-0086) settles membership; the value is the type's **shape** — one of `Unary`, `Binary`, `Multi` (Three shapes by G span count). Keying by coverage class rather than raw endset honours ASN-0086's TypeEquivalence (lifting L8, ASN-0043).

The registry value is the shape alone — *not* a type name; any human-readable label a type bears ("citation," "comment," "counterpart") is an app-side convention over addresses, not substrate state.

An app *declares* a type by placing its `[K_j] ↦ shape` entry in `Σ_init.registry` before the dynamics begin — the construction of `Σ_init` is the only act that writes the registry.

A registry is well-formed when every stored representative lies in `T_admissible`, shape values lie in `{Unary, Binary, Multi}`, and *coverage-class keys are unique*: no two entries have `~`-equal keys.

**C0 (RegistryWellFormedness).** `Σ_init.registry` is well-formed (above) and finite: `|Σ_init.registry| < ∞`.

We write `shape(K)` for the shape the well-formed registry — a partial function of coverage classes (above) — records for `[K]`; so `shape(K)` depends only on `[K]`, defined exactly on the registered coverage classes.

## Shape-conformance

The shapes are stated in terms of the span count `|e|` of an endset; F and G are both endsets. The gate measures span count, not coverage — and the two measures diverge in both directions. A single unit-depth span `(a, δ(1, #a))` is one span — `|{(a, δ(1, #a))}| = 1` — yet its coverage is `{t : a ≼ t}`, generally infinite (PrefixSpanCoverage, ASN-0043): one span carries unbounded coverage. Conversely, a source presenting one contiguous extent as two abutting spans has `|F| = 2` and fails every shape even though its coverage equals a conformant one-span F's. A witness: split `F₁ = {(a, δ(2, #a))}` into `F₂ = {(a, δ(1, #a)), (m, δ(1, #a))}`, writing `m = a ⊕ δ(1, #a)` and `b = a ⊕ δ(2, #a)`. Both F₂ spans are T12-well-formed — OrdinalShift (ASN-0034) preserves length, so `#m = #a` and each action point is `#a` — and the second's upper endpoint is `m ⊕ δ(1, #a) = b` (TS3, ShiftComposition, ASN-0034). Each well-formed span's start lies strictly below its end (TA-strict, StrictIncrease, ASN-0034), so `a < m` and `m < b`: the two half-open intervals genuinely abut at `m`. With that ordering in hand, T1 trichotomy at `m` and transitivity across it give the mutual inclusion `{t : a ≤ t < m} ∪ {t : m ≤ t < b} = {t : a ≤ t < b}`, i.e. `coverage(F₂) = coverage(F₁)`, yet `|F₂| = 2` while `|F₁| = 1`: coverage-equal sources can differ in span count. Slot 3's coverage class *selects* which span-count constraint applies to slots 1–2.

The predicate `Sh-conf(K, F, G)` is defined only for *registered* K — those for which the registry records a shape. For an unregistered K, `shape(K)` does not exist and `Sh-conf(K, F, G)` carries no truth value. For a typed tuple `(F, G, K)` under a type K registered with shape s, `Sh-conf(K, F, G)` holds when:

- Unary: `|F| = 1` and `G = ∅` (equivalently `|G| = 0`);
- Binary: `|F| = 1` and `|G| = 1`;
- Multi: `|F| = 1` and `|G| < ∞`.

For Multi the conjunct `|G| < ∞` holds for *every* endset by `Endset = 𝒫_fin(Span)`, so Multi places no real bound on G's span count — it is the unrestricted, permissive shape that subsumes Unary and Binary, constraining only F.

`Sh-conf` consults no state-indexed address set: it imposes no residence check, so endset spans may reference any address, including ghost addresses at which nothing is stored. L4 and L9 (ASN-0043) permit this, and the framework inherits the permission unchanged.

## The shape-gated emit

ASN-0086's `K.λ` step carries, per its contract (StateTransition, ASN-0086), the preconditions L3 on the emitted value (arity ≥ 3, non-empty type slot), home allocation — `home(a) ∈ dom(Σ.M)` for the emitted key `a`, without which the step would break L1a (ASN-0043) — and key freshness (`a ∉ dom(Σ.L)`); call these three the *inherited precondition set*. Nothing in it inspects span counts, so the bare `→` of ASN-0086 *admits* shape-non-conforming tuples. This framework **refines** the emit step, and with it the *transition relation*: ASN-0086's `→ ≡ K.σ ∪ K.α ∪ K.λ` becomes

`→_sh ≡ K.σ ∪ K.α ∪ K.λ_sh`,

the shape-gated step `K.λ_sh` replacing `K.λ`. The step `K.λ_sh` is `K.λ` with three added preconditions: (0) *the emitted value is a standard triple* (StandardTriple, ASN-0043) — arity 3; (i) *K is registered*; and (ii) `Sh-conf(K, F, G)`. Each precondition makes the next well-defined: (0) binds all three symbols to the deposited value's slots — `F = e₁` and `G = e₂`, the value's only two content slots, the pair `Sh-conf` reads, and `K = e₃`, its type slot (slot 3 by StandardTriple's convention, the `.type` accessor, ASN-0043) — so (i) and (ii) test the deposited value itself, not a caller-supplied parameter; and (i) supplies `shape(K)` (defined for registered K, The registry), so `Sh-conf(K, F, G)` (partial on unregistered K, Shape-conformance) is well-defined wherever (ii) is reached. The refinement is confined to the guard: `K.λ_sh` adds only preconditions to `K.λ`, so its C/M/L effect — the deposit of the value at one fresh key — and its C/M/L frame are identical to `K.λ`'s; added preconditions restrict *when* a step fires, not *what* it does. Call this **effect-identity**. The inherited contract guarantees that key *fresh*, not where it lands.

**Definition (Reachability).** The refinement replaces ASN-0086's step relation, so its reachability notion (Definition — Reachability, ASN-0086) cannot be inherited; we rebuild it over the gated relation. `Σ →_sh* Σ'` is the reflexive-transitive closure of `→_sh`; when it holds we call Σ' a *`→_sh*`-successor* of Σ. A state is *`→_sh*`-reachable* iff `Σ_init →_sh* Σ`, with `Σ_init` the registry-adjoined initial state (Registry permanence).

This gate yields the framework's safety guarantee. **P3 (Sh-confWellFormedness).** Every value a `→_sh`-step adjoins to `dom(Σ.L)` is a standard triple `(F, G, K)` whose K is registered and for which `Sh-conf(K, F, G)` holds. It is immediate: `K.λ_sh` is the only step kind that extends `dom(Σ.L)`, and (0), (i), (ii) are among its preconditions — so every deposited value is a standard triple of arity 3 by (0), with K registered by (i) and conforming to K's shape by (ii) — each verdict read where preconditions are read, at the firing step's pre-state.

One class of ASN-0086 emits falls outside `→_sh` entirely. The `|F| = 1` rule (Single-source) admits no empty-from source, and `K.λ_sh`'s precondition (ii) enforces it: `Emit_K` is total over `Endset × Endset` and `∅ ∈ Endset`, so `Emit_K(Σ, d, ∅, G)` is a legitimate ASN-0086 invocation, yet — carrying no F span — it has `|F| = 0`; every registrable shape requires `|F| = 1`, so for a registered K precondition (ii) fails and for an unregistered K precondition (i) fails, and either way the emit has **no** `→_sh` image. ASN-0086's `Nullify(Σ, d_retr, a) ≡ Emit_R(Σ, d_retr, ∅, {(a, δ(1, #a))})` is one such empty-from emit, so it too has no `→_sh` image. Retraction must therefore be re-expressed as a single-source emit before the framework can gate it (Retraction as an attributed Binary).

A second class falls outside `→_sh` for a different reason — precondition (0) itself. ASN-0086's `K.λ` admits any arity `N ≥ 3`, but precondition (0) restricts `K.λ_sh` to arity *exactly* 3, so every `N > 3` emission has **no** `→_sh` image. The path beyond either exclusion — the multi-span source (Single-source) and richer arity — is Open Question 6.

## Registry permanence

Write `π(Σ) = (Σ.C, Σ.M, Σ.L)` for the *forgetful projection* that drops the registry, returning an ASN-0086 three-component state. The framework constructs `Σ_init` by adjoining the registry to ASN-0086's three initial components, altering none of them. Two consequences follow. First, forgetting the registry recovers ASN-0086's own initial state exactly: `π(Σ_init) = Σ_init^{0086}`. Second, its base link store is empty, `Σ_init.L = ∅`, inherited from ASN-0086's base state. To show the registry never drifts we reconcile it with the transition relation: we extend the frame condition of each `→_sh` step kind (The shape-gated emit) with the registry as an additional framed component:

- K.σ: `Σ'.C = Σ.C`, `Σ'.L = Σ.L`, `Σ'.registry = Σ.registry`;
- K.α: `Σ'.M = Σ.M`, `Σ'.L = Σ.L`, `Σ'.registry = Σ.registry`;
- K.λ_sh: `Σ'.C = Σ.C`, `Σ'.M = Σ.M`, `Σ'.registry = Σ.registry`.

**P1 (RegistryInvariance).** At every `→_sh*`-reachable state, `Σ.registry = Σ_init.registry` — the registry never drifts. This follows by induction on the length of a `→_sh*`-derivation: the base case `Σ = Σ_init` is immediate, and each step preserves `Σ.registry = Σ_init.registry` by the frame condition for whichever of the three kinds it is.

Precondition (i) of `K.λ_sh` requires deciding whether the emitted `[K]` is a registered key. By P1 the registry never grows, so by C0 (The registry) it has finitely many keys at *every* reachable state; deciding (i) is then deciding `coverage(K) = coverage(K_j)` against each of the finitely many stored representative endsets `K_j`, and each such test is decidable by CoverageEqualityDecidable (ASN-0086) because it operates on the endsets `K`, `K_j` directly.

The registry's invariance (P1) makes a registered type's shape stable across states. **P2 (ShapeStability).** For any *registered* K, `shape(K)` takes the same value at every `→_sh*`-reachable state: since `shape(K)` is read from the P1-invariant registry, the same K cannot carry one shape at Σ and another at Σ'.

`Sh-conf` respects `~` and is stable on registered types. It respects `~` because for `K ~ K'` it reads only the span counts `|F|`, `|G|` and `shape(K) = shape(K')`, so `Sh-conf(K, F, G) = Sh-conf(K', F, G)`. It is stable because for registered K it reads only `(F, G)` and `shape(K)`, and since `shape(K)` is stable across states (P2), `Sh-conf(K, F, G)` evaluates the same against Σ as against any Σ' reachable from Σ. Moreover registration status is itself state-independent by P1 — K is registered at Σ iff registered at Σ' — so the predicate is *defined* at Σ exactly when it is defined at Σ'. **P4 (Sh-confStateIndependence).** For any *registered* K, any F, G, and any reachable Σ, Σ', `Sh-conf(K, F, G)` is defined at both states and its verdict at Σ equals its verdict at Σ'.

## The projection bridge

Registry permanence introduced the forgetful projection `π`. We now show it is a *bridge*: it carries this framework's gated dynamics onto ASN-0086's ungated dynamics.

**Lemma (ProjectionBridge).** `π` maps every `→_sh`-step to an ASN-0086 `→`-step, and hence every `→_sh*`-reachable state of this framework to a state `→*`-reachable from ASN-0086's initial state.

*Proof.* Each `→_sh`-step preserves the registry in its frame (Registry permanence) and acts on the C/M/L components exactly as the corresponding ASN-0086 step: a K.σ-step as `K.σ`, a K.α-step as `K.α`, and a `K.λ_sh`-step as a `K.λ` step — the last by effect-identity, its C/M/L action being `K.λ`'s. Hence whenever `Σ →_sh Σ'`, `π(Σ) → π(Σ')` in ASN-0086's relation. By induction on derivation length, `π` maps every `→_sh*`-reachable state to a state `→*`-reachable from ASN-0086's initial state: at the base, `π(Σ_init) = Σ_init^{0086}` (Registry permanence), trivially `→*`-reachable from itself; and each step extends a `→`-derivation rooted at `Σ_init^{0086}` by the projected step just exhibited. ∎

The bridge has three consequences.

**(B1) Shared components.** Σ and `π(Σ)` share their C, M, and L components. Every ASN-0086 state-indexed function reads only C/M/L — an ASN-0086 state has nothing else — so each agrees at Σ and `π(Σ)`, and is thereby well-defined on this note's four-component states by evaluation at the projection, `f(Σ) := f(π(Σ))`. In particular, since `a_emit` reads only M and L, `a_emit(π(Σ), d) = a_emit(Σ, d)` and `dom(π(Σ).L) = dom(Σ.L)`; consequently `A_rel^{π(Σ)} = A_rel^Σ` (AddressPartition, ASN-0086, gives `A_rel^Σ = dom(Σ.L)`).

**(B2) Lemma transfer.** Take any ASN-0086 result whose conclusion is a predicate over the C/M/L components of a single `→*`-reachable state. For each state Σ this note reasons about, `π(Σ)` is `→*`-reachable (ProjectionBridge), so the result holds at `π(Σ)`; since it constrains only the shared C/M/L components, its conclusion transfers to Σ directly. B2 yields no `→_sh`-successors: an existence-of-successor conclusion `∃ Σ' : Σ → Σ' ∧ …` transfers only to a `→`-successor of `π(Σ)`, which need not lift to a `→_sh`-step of Σ. A transition invariant of ASN-0086 (quantified over `→`-steps, e.g. L12) transfers only across a genuine `→_sh`-step `Σ →_sh Σ'`, whose projection `π(Σ) → π(Σ')` is the single ASN-0086 step it constrains.

**(B3) Path transfer.** Take any ASN-0086 result whose hypotheses are predicates over the C/M/L components of a single `→*`-reachable state and whose conclusion asserts, at every `→*`-successor of that state, again a predicate over C/M/L components — the path-quantified category B2 excludes. Such a result transfers: whenever its hypotheses hold at a `→_sh*`-reachable Σ, its conclusion holds at every `→_sh*`-successor Θ of Σ. For ProjectionBridge's step mapping gives, by induction on the derivation `Σ →_sh* Θ`, `π(Σ) →* π(Θ)`; the hypotheses, reading only components Σ shares with `π(Σ)` (B1), hold at `π(Σ)`, itself `→*`-reachable by ProjectionBridge; the result applied at `π(Σ)` therefore reaches its `→*`-successor `π(Θ)`; and B1, applied at the `→_sh*`-reachable Θ, carries the per-successor conclusion from `π(Θ)` back to Θ. R6c (RestorationByReemission, ASN-0086) is the canonical instance — hypotheses pure L-reads at one state, conclusion excluding a tuple from its type's active subset at every `→*`-successor.

One exclusion deserves its own statement: *layer-scoped* results do not transfer at all. ProjectionBridge delivers `→*`-reachability, never *layer*-reachability (RelationalLayer, ASN-0086): `→_sh` gates by shape, not by ASN-0086's discipline commitment, and a Binary-registered retraction type admits gate-clearing `Emit_R` steps with non-unit to-spans (Retraction as an attributed Binary), each projecting to an `L_R`-growing `→`-step that is no `Nullify`. A projected run may therefore violate the discipline commitment, leaving `π(Σ)` outside the layer-reachable states, and ASN-0086's layer-scoped results — its disciplined-domain wp simplification, its unit-depth-discipline discharge — are then unavailable at `π(Σ)` and outside transfer range.

## Gate realizability

The one existence-of-successor result this framework needs — that a *conforming* emit actually fires — lies outside B2's scope (The projection bridge). We establish it directly, by applying ASN-0086's `Emit_K` at `π(Σ)` and manually lifting its `K.λ` step back to a `K.λ_sh` step. The lift needs one fact about registered types.

**Lemma (RegisteredAdmissible).** Every registered K satisfies `K ∈ T_admissible`. By C0 (RegistryWellFormedness, The registry) the registry stores, for K's coverage class, a finite representative endset `K_j ∈ T_admissible`, and — by the coverage-class keying established there — "K registered" means `coverage(K) = coverage(K_j)`. Non-emptiness must transfer from the stored representative to the emitted type, since the emitted triple's type slot is `K`, not `K_j`: `K_j ∈ T_admissible` is non-empty, so it contains a span `(s, ℓ)`, T12-well-formed by `Endset = 𝒫_fin(Span)` (ASN-0043) — `ℓ > 0` with action point at most `#s`. These are exactly the hypotheses of TA-strict (StrictIncrease, ASN-0034), giving `s < s ⊕ ℓ`, hence `s ∈ {t : s ≤ t < s ⊕ ℓ} ⊆ coverage(K_j)`, so `coverage(K_j) ≠ ∅`; hence `coverage(K) = coverage(K_j) ≠ ∅`, so `K ≠ ∅`, i.e. `K ∈ T_admissible`.

**P5 (GateRealizability).** For any `→_sh*`-reachable Σ, any `d ∈ dom(Σ.M)`, any registered K, and any `F, G ∈ Endset` with `Sh-conf(K, F, G) = ⊤`, there exists Σ' with `Σ →_sh Σ'` depositing the standard triple `(F, G, K)` at the fresh address `a = a_emit(Σ, d)`:

`a ∉ dom(Σ.L) ∧ a ∈ dom(Σ'.L) ∧ Σ'.L(a) = (F, G, K) ∧ home(a) = d`,

with Σ' itself `→_sh*`-reachable.

*Proof.* The premises are exactly `Emit_K`'s hypotheses at the projected state, the gate conditions hold for a conforming triple by inspection, and the only real work is lifting `Emit_K`'s ungated `K.λ` step — fired at the pinned address `a_emit` — back to a gated `K.λ_sh` step.

First, `K ∈ T_admissible` by Lemma (RegisteredAdmissible), since K is registered. The emitted type slot is therefore non-empty — discharging both `Emit_K`'s `K ∈ T_admissible` precondition and L3's non-empty-type-slot clause. With `F, G ∈ Endset`, the standard triple `(F, G, K)` discharges L3 directly through R0's value-shape consequence — arity 3, both content slots in `Endset`.

Second, by the projection bridge (Lemma ProjectionBridge), `π(Σ)` is `→*`-reachable, so ASN-0086's `Emit_K` operation is applicable at `π(Σ)`. `Emit_K(π(Σ), d, F, G)` — with `d ∈ dom(Σ.M) = dom(π(Σ).M)` and `K ∈ T_admissible` (above) — invokes a `K.λ` step at home `d`, depositing `(F, G, K)`, and pins its fresh address to `a = a_emit(π(Σ), d)` by the operation's contract; it returns `(Σ_{0086}, a)` with `a ∉ dom(π(Σ).L)`, `a ∈ dom(Σ_{0086}.L)`, `home(a) = d`, `Σ_{0086}.L(a) = (F, G, K)`. The bridge's shared-components consequence (B1) gives `a_emit(π(Σ), d) = a_emit(Σ, d)` — the address P5 names — and `dom(π(Σ).L) = dom(Σ.L)`, so `a ∉ dom(Σ.L)`.

Third, lift the step. The underlying ASN-0086 step is the `K.λ` step that `Emit_K` realizes at the pinned address `a_emit(Σ, d)`. Form Σ' by adjoining the unchanged registry to `Σ_{0086}`: `Σ'.C = Σ_{0086}.C`, `Σ'.M = Σ_{0086}.M`, `Σ'.L = Σ_{0086}.L`, `Σ'.registry = Σ.registry`. We verify the pair `(Σ, Σ')` is a `K.λ_sh`-step. By effect-identity its C/M/L effect is `K.λ`'s, realized by the `Emit_K` step at `a_emit`, and its registry frame `Σ'.registry = Σ.registry` holds by construction. Its preconditions: the inherited precondition set (The shape-gated emit) holds — L3 discharged above, home allocation by premise (`home(a) = d ∈ dom(Σ.M)`), key freshness by `Emit_K`'s contract carried across B1 (`a ∉ dom(Σ.L)`, above); (0) arity 3 holds — the value is the standard triple `(F, G, K)`; (i) K registered — premise; (ii) `Sh-conf(K, F, G) = ⊤` — premise. All hold, so the pair `(Σ, Σ')` is a `K.λ_sh`-step, hence `Σ →_sh Σ'`, and Σ' is `→_sh*`-reachable. Its post-state map gives `a ∈ dom(Σ'.L)`, `Σ'.L(a) = (F, G, K)`, `home(a) = d`, completing the claim. ∎

## Retraction as an attributed Binary

With the gate and the projection bridge in hand, we re-express the un-gateable empty-from `Nullify` (The shape-gated emit) as a single-source emit the framework can gate. To obtain a gated retraction an app registers R as **Binary** and routes through the one-span wrapper `Nullify_Binary(Σ, d_retr, a) ≡ Emit_R(Σ, d_retr, {r}, {(a, δ(1, #a))})` — canonical from-fill `r = (d_retr, δ(1, #d_retr))`, giving `|F| = |G| = 1`. The target stays in G, so ASN-0086's `nullified`/`L_R`/active-subset machinery — all reading `coverage(G')` and ignoring F — carries over unchanged.

The `|F| = 1` rule also reshapes the *attribution* dimension, which that G-reading machinery does not see. ASN-0086's `Nullify` carries an empty from-set, which its Convention RetractionDirectionality reads as an *unattributed* retraction — the from-set "is left empty for unattributed retractions" — so the form `→_sh` forecloses is precisely *unattributed* retraction. Nor is the from-fill `r` inert padding: by PrefixSpanCoverage (ASN-0043), `coverage({(d_retr, δ(1, #d_retr))}) = {t : d_retr ≼ t}`, the entire subtree of the retracting document — all its versions, content, and links — so `Observe_R`, matching a from-pattern `F̂` against `coverage(F)`, now matches every *wrapper-routed* retraction homed at `d_retr` — every retraction carrying the canonical from-fill — against any under-`d_retr` pattern. The qualifier is necessary: the gate enforces `|F| = 1`, not `F = {r}`, so a gated `Emit_R` whose one span lies elsewhere clears Binary registration yet escapes the match — Step 1 (Worked illustration) is such an emit, homed at `d` with from-set `[c₁]`, and the under-`d` pattern `F̂ = {d}` fails `F̂ ⊆ coverage([c₁])`, since `#c₁ > #d` rules out `c₁ ≼ d`. The from-fill convention is therefore normative for `Nullify_Binary` — the wrapper writes `F = {r}` by construction — and the `Observe_R` consequence is scoped to retractions routed through it. The convention: F answers *who retracts*, at whole-document granularity — the canonical metalink pattern of the supersession and author links, which point "to the whole document" [LM 4/52–4/53] — while G, unchanged, carries *what is retracted*.

Binary registration is strictly weaker than ASN-0086's UnitDepthRetractionDiscipline in *two* independent ways, and single-tuple-scope survives only if the app closes *both* gaps. First, Binary gates G by span count alone, so a single G-span of non-unit length — say `(t, δ(2, #t))`, covering a contiguous multi-address range — is equally Binary-conformant, hence a legal `→_sh`-step that withdraws a whole region at once. The unit-depth wrapper closes this first gap by writing the canonical `{(a, δ(1, #a))}` to-span by construction. Second — and this gap the gate cannot see at all — even the unit-depth wrapper attains R-Scope's single-tuple-scope result `{t : a ≼ t} ∩ A_rel^{Σ'} = {a}` only when its *target* `a` satisfies R-Scope's hypothesis P-tgt: `a ∈ A_rel^Σ` (an existing link address) or `a = a_emit(Σ, d_retr)` (the fresh self-emit address). The unit-depth *form* is necessary but not sufficient: R-Scope's conclusion rests on R0a (FlatLinkDomain) — link addresses form a prefix-antichain, so the only link `≼`-above a *leaf* target is the target itself. Concretely, aim the wrapper at an existing leaf link `a = ℓ₁ = 1.1.0.1.0.1.0.2.1 ∈ A_rel^Σ`, homed at `d_retr = 1.1.0.1.0.1` and element-level with `zeros(ℓ₁) = 3`, `#E(ℓ₁) = 2`. P-tgt's first disjunct `a ∈ A_rel^Σ` holds — equally at `π(Σ)`, where R-Scope reads it, by B1's `A_rel^{π(Σ)} = A_rel^Σ` — so R-Scope applies; and because `ℓ₁` is itself a link address, R0a's antichain leaves it the only member of `A_rel^{Σ'}` with `ℓ₁ ≼ ·` (any link `≼`-above `ℓ₁` equals `ℓ₁`), so `{t : ℓ₁ ≼ t} ∩ A_rel^{Σ'} = {ℓ₁}` — single-tuple-scope holds. Aim the same wrapper at an interior prefix and that antichain argument lapses. Take the ghost link-subspace root `a = d_retr.0.s_L` — concretely `1.1.0.1.0.1.0.2` for the same `d_retr` — for which `zeros(a) = 3` but `#E(a) = 1`. The first P-tgt disjunct fails by L1b (LinkElementFieldDepth, ASN-0043): every link address has element-field depth at least 2, an invariant holding at the `→*`-reachable `π(Σ)` (ProjectionBridge) and carried to Σ by B1's shared L-component, so `a`, with `#E(a) = 1`, has `a ∉ dom(Σ.L)`. The second fails by EmitAddress's two branch shapes (ASN-0086): the first-emission branch returns `d_retr.0.s_L.1`, with `#E = 2`; the subsequent branch returns `inc(ℓ_prev, 0)` for a chain maximum `ℓ_prev ∈ dom(Σ.L)`, T4-valid by L0b (ASN-0043, holding at the `→*`-reachable `π(Σ)` and carried to Σ like L1b above), whose `#E(ℓ_prev) ≥ 2` (L1b again) survives the sibling advance — on a T4-valid input it increments only the terminal component (TA5(c), TA5-SigValid, as in CPP, ASN-0043), leaving every zero in place and `#E` unchanged — so `#E(a_emit(Σ, d_retr)) ≥ 2 ≠ 1 = #E(a)` and `a ≠ a_emit(Σ, d_retr)`. P-tgt fails on both disjuncts. The wrapper `Emit_R(Σ, d_retr, {r}, {(a, δ(1, #a))})` has `|F| = |G| = 1` and *clears the Binary gate*, yet `coverage({(a, δ(1, #a))}) = {t : a ≼ t}` is the entire link subspace homed at `d_retr`, so at the wrapper's post-state Σ' the intersection `{t : a ≼ t} ∩ A_rel^{Σ'}` is *exactly* the set of links homed there — every prior link (`1.1.0.1.0.1.0.2.1`, `1.1.0.1.0.1.0.2.2`, …) and the wrapper's own fresh emitter `b = a_emit(Σ, d_retr)` alike, each carrying the prefix `a` (home `d_retr`, subspace component `s_L` by L0) — while omitting the ghost `a` itself, the L1b argument above applying verbatim at the `→_sh*`-reachable Σ' to give `a ∉ A_rel^{Σ'}`. The intersection thus differs from `{a}` in both directions — it acquires the full homed set, `b` included, and lacks `a` — failing single-tuple-scope on both counts, and nothing in `→_sh` rejects the call. Single-tuple-scope is therefore an *app obligation* — route through the unit-depth wrapper **and** supply a P-tgt-valid target — not a guarantee `→_sh` discharges. And the first gap's cost extends to unfilled chain slots — Corollary RangeSterilization (Range sterilization).

R-Scope (ASN-0086) is proven for the empty-from Nullify over ASN-0086's three-component `→*`-reachable states, not for this Binary wrapper. With a P-tgt-valid target (above), its conclusion nonetheless reaches the wrapper's post-state in three moves. *Bind the post-state.* The Binary wrapper's value is shape-conforming: R is registered Binary and `|F| = |{r}| = 1`, `|G| = |{(a, δ(1, #a))}| = 1`, so `Sh-conf(R, {r}, {(a, δ(1, #a))}) = ⊤`. With `d_retr ∈ dom(Σ.M)` (Nullify's P0), the conforming gated emit therefore exists by P5 (GateRealizability, Gate realizability): let `Σ →_sh Σ'` be the `→_sh`-step it takes, depositing `({r}, {(a, δ(1, #a))}, R)` at the fresh address `a_emit(Σ, d_retr)`. *Apply R-Scope within ASN-0086.* P-tgt crosses the projection intact: both its disjuncts read only B1-shared components — `A_rel^{π(Σ)} = A_rel^Σ` and `a_emit(π(Σ), d_retr) = a_emit(Σ, d_retr)` (B1) — so `a`, meeting P-tgt at Σ, meets it at `π(Σ)`. By ProjectionBridge `π(Σ)` is `→*`-reachable, so R-Scope applies to the empty-from `Nullify(π(Σ), d_retr, a) = Emit_R(π(Σ), d_retr, ∅, {(a, δ(1, #a))})`, whose post-state `Ψ` satisfies `{t : a ≼ t} ∩ A_rel^{Ψ} = {a}`. This is R-Scope at its native transition, *not* a B2 transfer: `Ψ` is not `→_sh`-reachable (the empty-from Nullify is not a `→_sh`-step, The shape-gated emit), so B2 does not reach it (The projection bridge). *Frame the two post-states together* — the load-bearing step. The wrapper's underlying ASN-0086 step `π(Σ) → π(Σ')` (by ProjectionBridge) and the Nullify `π(Σ) → Ψ` both call `a_emit` on the *same* `(π(Σ), d_retr)`, and `a_emit` is blind to F, so both emit at the *identical* fresh address and yield the *same* post-state link domain: `dom(π(Σ').L) = dom(Ψ.L)`, hence `A_rel^{π(Σ')} = A_rel^{Ψ}`. The two post-states differ only in the value stored at that address (`F = ∅` for Nullify, `F = {r}` for the wrapper), which neither `A_rel` nor the fixed target subtree `{t : a ≼ t}` reads. Substituting, `{t : a ≼ t} ∩ A_rel^{π(Σ')} = {t : a ≼ t} ∩ A_rel^{Ψ} = {a}`. Finally B1, applied at the `→_sh*`-reachable Σ', shares the L-component — `A_rel^{π(Σ')} = A_rel^{Σ'}` — giving `{t : a ≼ t} ∩ A_rel^{Σ'} = {a}` at the wrapper's four-component post-state.

Collected as an operation contract, over `→_sh*`-reachable Σ:

**Nullify_Binary** — `Nullify_Binary(Σ, d_retr, a) ≡ Emit_R(Σ, d_retr, {r}, {(a, δ(1, #a))})`, canonical from-fill `r = (d_retr, δ(1, #d_retr))`.

*Preconditions.* **P0**: `d_retr ∈ dom(Σ.M)` (ASN-0086's own). **P-reg**: [R] is registered Binary — the section's standing configuration. P-reg has no ASN-0086 analog and cannot be dropped: for unregistered [R] every `Emit_R`, this wrapper included, has no `→_sh` image at all (precondition (i) of `K.λ_sh`) — a failure mode the ungated `Nullify` could not exhibit. The target `a` carries no precondition — `(a, δ(1, #a))` is T12-well-formed for any tumbler (Nullify, ASN-0086); P-tgt in particular is *not* assumed, it conditions the postconditions below.

*Effect.* The `→_sh`-step exhibited above (*Bind the post-state*, by P5): `Σ →_sh Σ'` deposits `({r}, {(a, δ(1, #a))}, R)` at the fresh emitter `b = a_emit(Σ, d_retr)` — `b ∉ dom(Σ.L)`, `b ∈ dom(Σ'.L)`, `home(b) = d_retr`, `Σ'.L(b) = ({r}, {(a, δ(1, #a))}, R)` — with Σ' itself `→_sh*`-reachable and the stored value permanent thereafter (L12, transferred across each later `→_sh`-step by B2).

*Frame.* `Σ'.C = Σ.C`, `Σ'.M = Σ.M`, `Σ'.registry = Σ.registry` — `K.λ_sh`'s frame (Registry permanence).

*Postconditions.* The step adjoins exactly the fresh key, so `A_rel^{Σ'} = A_rel^Σ ∪ {b}`; then:

- *Coverage nullification, unconditional.* `{t : a ≼ t} ∩ A_rel^{Σ'} ⊆ nullified(Σ')` — the deposited tuple lies in `L_R^{Σ'}` with to-coverage `{t : a ≼ t}` (PrefixSpanCoverage), so every resident link address under the target is nullified.
- *Target nullification iff residence.* `a ∈ nullified(Σ') ⟺ a ∈ A_rel^{Σ'} ⟺ P-tgt at Σ` — the to-coverage contains `a` by reflexivity of `≼`, so Definition Nullified's existential holds at `a` and membership turns on its residence clause `a ∈ A_rel^{Σ'}`, which by the domain growth above is `a ∈ A_rel^Σ ∨ a = a_emit(Σ, d_retr)`: exactly P-tgt. A ghost target is *not itself* nullified — only the link addresses under it are.
- *Single-tuple scope iff P-tgt.* `{t : a ≼ t} ∩ A_rel^{Σ'} = {a}` holds iff P-tgt holds at Σ — *if*: the three-move transfer above; *only if*: a failed P-tgt leaves `a ∉ A_rel^{Σ'}` (previous clause), so the intersection omits `a`.
- *Persistence.* The nullification established by the preceding clauses is permanent — the analog of ASN-0086's "persisting thereafter by R6a" at its Nullify block. Membership in `nullified(Σ')` persists across every later `→_sh`-step: R6a (RetractionStability, ASN-0086) is a transition invariant, within B2's transition-invariant scope (The projection bridge), so it transfers across each genuine step `Σ' →_sh Σ''` — whose projection `π(Σ') → π(Σ'')` is the single `→`-step R6a constrains, `nullified` a pure L-read shared by B1 — and induction along the derivation gives `nullified(Σ') ⊆ nullified(Θ)` at every `→_sh*`-successor Θ of Σ'. And every nullified resident stays out of its type's active subset: for any `K ∈ T_admissible` and any `(a', F', G') ∈ L_K^{Σ'}` with `a' ∈ nullified(Σ')`, `(a', F', G') ∉ A_K^Θ` at every `→_sh*`-successor Θ — by R6c (RestorationByReemission, ASN-0086), whose hypotheses are pure L-reads holding at Σ' and whose path-quantified conclusion transfers by B3 (The projection bridge).

The *operation set* an app invokes refines ASN-0086's `{Emit_K, Observe_K, Nullify}`, in step with the transition relation, to `{Emit_K, Observe_K, Nullify_Binary}`. Of the three, only `Observe_K` — a pure read — carries over untouched: it inspects state without extending `dom(Σ.L)`, so the emit refinement does not touch it. `Emit_K` is now gated (The shape-gated emit), and the empty-from `Nullify` is superseded by the attributed-Binary wrapper `Nullify_Binary` specified above.

## Weakest precondition of the shape-gated emit

With the gate (The shape-gated emit) and the projection bridge established, we take the postcondition `(a, F, G) ∈ A_K^{Σ'}` — the emitted tuple lands in the *active* subset of its type at the post-state — and reason backward, refining ASN-0086's Case-2 wp. One convention first, because the gate makes enabledness itself contingent: we read wp in the *attainability* sense — `wp(S, R)` holds at Σ iff S fires at Σ and the post-state so reached satisfies R. A step whose guard blocks reaches no post-state; attainability renders its wp *false* there, where a partial-correctness reading would render it vacuously true. Under this convention the rule for a guarded operation is unconditional in R: `wp(g → S, R) ≡ g ∧ wp(S, R)` — on `¬g` nothing fires, so the wp is false and the left conjunct records it; on `g` the guarded operation is exactly its body S.

ASN-0086 (wp Case 2) gives, for the ungated `Emit_K` over ASN-0086's `→*`-reachable states, with fresh address `a = a_emit(Σ, d)`:

`wp(Emit_K(Σ, d, F, G), (a, F, G) ∈ A_K^{Σ'}) ≡ d ∈ dom(Σ.M) ∧ (K ≁ R ∨ a_emit(Σ, d) ∉ coverage(G)) ∧ ¬(∃ (b, F', G') ∈ L_R^Σ :: a_emit(Σ, d) ∈ coverage(G'))`.

The equivalence reaches this note's `→_sh*`-reachable Σ not by B2 — its left side quantifies over the operation's post-state, which B2 excludes — but by ProjectionBridge, effect-identity, and B1 jointly. ProjectionBridge makes `π(Σ)` `→*`-reachable, so Case 2 holds *at* `π(Σ)` by its own quantification. To carry it to Σ, view the gated emit as a guarded operation `g_sh → S` whose body S is the underlying `K.λ` action with the registry framed (effect-identity): S fired at Σ performs exactly the C/M/L step that `Emit_K` performs at `π(Σ)` — same enabledness (the inherited precondition set reads only C/M/L, shared by B1), same fresh address (`a_emit(Σ, d) = a_emit(π(Σ), d)`, B1), same deposited triple — and its post-state Σ' differs from `Emit_K`'s only by the adjoined registry (Gate realizability), which the postcondition `(a, F, G) ∈ A_K^{Σ'}`, a pure L-read, never consults. Case 2's right-hand side likewise reads only pre-state C/M/L, shared by B1. Hence `wp(S, (a, F, G) ∈ A_K^{Σ'})`, evaluated at Σ, *is* Case 2's right-hand side; the gate remains to be conjoined.

The three inherited conjuncts read: the home is an allocated document (C1); the emit is not a self-nullifying retraction — the `K ≁ R` escape (C2); and no pre-existing retraction tuple already covers the fresh address (C3). The added guard is `g_sh ≡ K registered ∧ Sh-conf(K, F, G)` — a *conditional* conjunction, the left conjunct guarding the right exactly as the gate orders (i) before (ii), so that `g_sh` is *false* (not undefined) at an unregistered K (`Sh-conf` partial there, Shape-conformance); precondition (0) is discharged by construction — the body always builds the arity-3 triple `(F, G, K)` — and contributes no wp conjunct. The attainability guard rule then gives:

`wp(Emit under →_sh, (a, F, G) ∈ A_K^{Σ'})`
`≡ {guard rule, attainability reading}`
`K registered ∧ Sh-conf(K, F, G) ∧ d ∈ dom(Σ.M) ∧ (K ≁ R ∨ a_emit(Σ, d) ∉ coverage(G)) ∧ ¬(∃ (b, F', G') ∈ L_R^Σ :: a_emit(Σ, d) ∈ coverage(G'))`.

The underlying `Emit_K` carries further enablement preconditions — its own `K ∈ T_admissible`, and the inherited precondition set (The shape-gated emit) beyond home allocation, which is C1 itself: L3 and key freshness. None contributes a wp conjunct. L3 and `K ∈ T_admissible` are discharged by precondition (0) — whose arity-3 triple satisfies L3's arity clause — the input typing `F, G ∈ Endset`, and Lemma (RegisteredAdmissible) (Gate realizability), which supplies `K ∈ T_admissible` and hence L3's non-empty type slot; key freshness the operation discharges itself, emitting at the fresh `a_emit(Σ, d)` (R0, ASN-0086).

Whether this weakest precondition is *strictly stronger* than `K.λ_sh`'s own precondition is a per-substrate question — the registry is fixed at construction, and each `Σ_init.registry` fixes its own family of reachable states. The division of labor is configuration-independent: the gate (`g_sh ≡ K registered ∧ Sh-conf(K, F, G)`, together with the inherited precondition set) governs only well-formedness — it *enables* the emit and deposits the conforming tuple into the *audit* slice `L_K^{Σ'}` — whereas the two remaining inherited conjuncts C2 and C3 govern *landing* in the *active* subset `A_K^{Σ'}`. The strictness is configuration-dependent. Whenever [R] is registered Binary or Multi, the wp is strictly stronger: **both** C2 and C3 can fail for a gate-clearing emit. C2, `(K ≁ R ∨ a_emit(Σ, d) ∉ coverage(G))`, fails for a *self-nullifying retraction* — `K ~ R ∧ a_emit(Σ, d) ∈ coverage(G)`, the retraction's own to-set covering its fresh address `a = a_emit(Σ, d)`. A gate-clearing witness is the Binary self-emit `Emit_R(Σ, d, {r}, {(a, δ(1, #a))})` with self-target `a = a_emit(Σ, d)` — the attributed Binary wrapper (Retraction as an attributed Binary) — whose `|F| = |{r}| = 1` and `|G| = 1` clear the gate where the empty-from Nullify it re-expresses has no `→_sh` image; under Multi registration the same self-emit clears the gate, its `|G| = 1 < ∞`. C3, `¬(∃ (b, F', G') ∈ L_R^Σ :: a_emit(Σ, d) ∈ coverage(G'))`, fails when a *pre-existing* `L_R` tuple already covers that address. Under either failure the tuple is *born nullified* — present in the audit slice `L_K^{Σ'}` yet absent from the active subset `A_K^{Σ'}`. Under the two remaining configurations the strictness lapses: with [R] unregistered or registered Unary, C2 and C3 hold at every gate-clearing emit over every reachable state — no `L_R` tuple exists, or every one carries empty to-coverage, and a gate-clearing `K ~ R` emit is impossible or Unary-forced to `G = ∅` (the configuration sweep, Range sterilization) — and the wp coincides with the operation's own precondition as a predicate over that substrate's reachable states.

What singles out C3 is not that it can fail — so can C2 — but that it is the conjunct *newly* live under `→_sh`. Under ASN-0086's unit-depth retraction discipline C3 was vacuous: unit-depth to-spans together with R0a (FlatLinkDomain) force `a_emit(Σ, d) ∉ coverage(G')` for every pre-existing `L_R` tuple — the disciplined-domain simplification of ASN-0086's wp Case 2. By Retraction as an attributed Binary, `→_sh` admits non-unit retraction to-spans whose coverage can include a fresh address, so C3 becomes live. C2's self-nullification, by contrast, is inherited from ASN-0086 and already live there.

## Reachable conformance

We lift P3's single-step guarantee to an invariant holding at every reachable state. **P6 (ReachableConformance).** For every `→_sh*`-reachable Σ and every `a ∈ dom(Σ.L)`, the stored value `Σ.L(a)` is a standard triple `(F, G, K)` whose K is registered and for which `Sh-conf(K, F, G) = ⊤`. *Derived* by induction on derivation length, with P6 itself as the induction hypothesis at the predecessor state. The base `Σ_init.L = ∅` (Registry permanence) holds vacuously. Each `→_sh`-step either leaves `dom(Σ.L)` unchanged (K.σ, K.α) or extends it by one tuple. For the tuple a step newly deposits, P3 supplies all three conjuncts — the standard-triple shape from precondition (0) of `K.λ_sh`, registration from (i), conformance from (ii) — but supplies them where preconditions are evaluated, at the pre-state Σ, while P6 asserts them at the post-state Σ'. The shape conjunct crosses unaided: it is a property of the deposited value alone, and the value at the fresh key in Σ' is the deposited one. The other two are state-indexed, and both endpoints are `→_sh*`-reachable — Σ by the induction context, Σ' as its `→_sh`-successor — so P1 (RegistryInvariance) carries registration across the step, the registry being invariant so K registered at Σ is K registered at Σ', and P4 (Sh-confStateIndependence) carries the conformance verdict, defined and identical at the two states. For a tuple already present, the three conjuncts persist by, in turn: L12 (LinkImmutability, ASN-0043), under which the stored value `(F, G, K)` — and hence its standard-triple shape — persists unchanged: by B2's transition-invariant scope (The projection bridge), L12 transfers across the genuine `→_sh`-step `Σ →_sh Σ'`, and B1 shares the L-component at both endpoints (`Σ.L = π(Σ).L`, `Σ'.L = π(Σ').L`); P1 (RegistryInvariance, Registry permanence), under which K's registration status persists, the registry being invariant so a type registered at Σ is registered at Σ'; and P4 (Sh-confStateIndependence), under which the conformance verdict persists, `Sh-conf(K, F, G)` being defined and evaluating identically at Σ and Σ'.

## Range sterilization

The weakest-precondition analysis left C3 newly live: a gate-clearing emit is born nullified when some pre-existing `L_R` tuple covers its fresh address. We now ask how much *future* emission a single such tuple can poison. The fresh address is not the app's to choose — `a_emit` is a function of state — so the question concerns the sibling chain `a_emit` walks, and the answer must cover both `a_emit` branches, the empty chain included.

Fix `d ∈ dom(Σ.M)` at a `→_sh*`-reachable Σ, and write `chain_d(j) = incʲ(d.0.s_L.1, 0)` for `j ≥ 0` — the enumeration in which L-ContiguousPrefix (ASN-0086) presents the homed-set: at every `→*`-reachable state the homed-set `{a' ∈ dom(Σ.L) : home(a') = d}` is the initial segment `{chain_d(j) : 0 ≤ j ≤ J_d^Σ}` for some `J_d^Σ ∈ ℤ_{≥-1}`, with unique T1-maximum `chain_d(J_d^Σ)` when non-empty. That conclusion is a single-state predicate over the B1-shared L and M components, so it transfers to this note's `→_sh*`-reachable states by B2, and we read `J_d^Σ` at Σ through B1. Call `f_d^Σ = J_d^Σ + 1` the *frontier* — the index of the first unfilled chain slot.

**Lemma (FrontierUnification).** At every `→_sh*`-reachable Σ and every `d ∈ dom(Σ.M)`, `a_emit(Σ, d) = chain_d(f_d^Σ)`. *Proof.* By B1, `a_emit(Σ, d) = a_emit(π(Σ), d)`; evaluate EmitAddress (ASN-0086) at `π(Σ)` by its two branches, whose branch criterion reads the homed-set (`home` and `origin` coincide on link addresses — Fact HomeOriginCoincidence, ASN-0086). If the homed-set is empty — `J_d^Σ = -1` — the first-emission branch returns `d.0.s_L.1 = chain_d(0) = chain_d(f_d^Σ)`: the empty chain is the `J_d^Σ = -1` instance of the same formula, not a separate regime. Otherwise `J_d^Σ ≥ 0` and the subsequent-emission branch returns `inc(ℓ_prev, 0)` at the homed-set's T1-maximum `ℓ_prev`, which L-ContiguousPrefix's unique-maximum clause pins to `chain_d(J_d^Σ)`; the branch thus returns `inc(chain_d(J_d^Σ), 0) = chain_d(f_d^Σ)`. Both branches name the frontier slot. ∎

The ascent argument below and the up-set realizability after it both carry a hypothesis we discharge first: every `chain_d(j)` is T4-valid. For a filled slot `j ≤ J_d^Σ` the address lies in `dom(Σ.L)` and L0b (ASN-0043) gives it; the sterilization analysis, however, quantifies over the *unfilled* slots `j > J_d^Σ` — exactly the slots a covering to-span sterilizes — where L0b is silent, so producibility discharges it instead. L1c (ASN-0043) cannot supply the base — it guarantees a chain only for *stored* link addresses, and in the `J_d^Σ = -1` case `chain_d(0) = d.0.s_L.1`, `a_emit`'s first-emission output, is itself unstored, EmitAddress (ASN-0086) naming that tumbler without producing it — so we exhibit the producing chain. Seed at the document node `d`: `d` is T4-valid with `zeros(d) = 2` by DocVal via S7d — an M-read holding at the `→*`-reachable `π(Σ)` and carried to Σ by B1, the same seeding L11a's chain argument uses. Step first by `k = 2` — precondition `zeros(d) = 2 ≤ 2` — seating the field-separating zero at position `#d + 1` (L1c's shape) and landing at `inc(d, 2) = d.0.1`, of length `#d + 2` and `zeros = 3`. Advance `s_L − 1` siblings, walking `d.0.1, d.0.2, …, d.0.s_L`: each `inc(·, 0)` increments only the terminal component of its input — the sig position, terminal on a T4-valid input (TA5(c), TA5-SigValid, ASN-0043), and T10a.4 carries T4-validity stepwise along the chain, so each advance's input qualifies — preserving length and every zero. Spawn one child by `k = 1` — precondition `zeros(d.0.s_L) = 3 ≤ 3`, the `k = 2` step having seated the third zero and the advances having preserved it — landing at `inc(d.0.s_L, 1) = d.0.s_L.1`, of length `#d + 3`. Every step has `kᵢ ∈ {0, 1, 2}` with its zeros precondition met, the first is `k₁ = 2`, and every length exceeds `#d`: a T10a-conforming chain of exactly L1c's shape from the T4-valid seed `d`, whose terminus `chain_d(0)` T10a.4 therefore certifies T4-valid. Each successor `chain_d(j+1) = inc(chain_d(j), 0)` extends that chain by one sibling advance, a conforming T10a step, across which T10a.4 again propagates T4-validity; induction on `j` then covers every chain element, filled or unfilled — the chain-extension pattern FSE (ASN-0043) already uses.

The chain ascends strictly: a sibling advance modifies only the sig position — for a T4-valid input the terminal position (TA5(c), TA5-SigValid, as in CPP, ASN-0043), and every input here is T4-valid by the discharge above — incrementing that component while preserving length and every earlier position, so `chain_d(j)` and `chain_d(j+1)` first differ at the terminal, where the latter is larger; hence `chain_d(j) < chain_d(j+1)` under T1, and `chain_d(j) < chain_d(j')` for `j < j'` by transitivity.

The ascent settles one more pinning, which the corollary's no-routing-around claim needs: a *raw* `K.λ_sh`-step — one not routed through `Emit_K` — inherits from `K.λ` only that its key is fresh (StateTransition, ASN-0086), not where the key sits. Chain position is forced by L-ContiguousPrefix at the step's two endpoints. A `K.λ_sh`-step `Σ' →_sh Θ` homed at `d` — its fresh key `a` having `home(a) = d` — grows `d`'s homed-set by exactly `{a}` and no other homed-set; both endpoint states are `→_sh*`-reachable, so both homed-sets are contiguous initial segments of the chain (L-ContiguousPrefix, transferred as above), and the chain is injective by its strict ascent, so `{chain_d(j) : 0 ≤ j ≤ J_d^{Σ'}} ∪ {a} = {chain_d(j) : 0 ≤ j ≤ J_d^Θ}` forces `J_d^Θ = J_d^{Σ'} + 1` with `a = chain_d(f_d^{Σ'}) = a_emit(Σ', d)` (FrontierUnification). Call this **frontier-landing**: every `K.λ_sh` deposit, raw or `Emit_K`-mediated, lands at the frontier of its home's chain and advances that frontier by one.

Now fix a retraction tuple `(b, F', G') ∈ L_R^Σ` with single-span to-endset `G' = {(g, ℓ)}` — when R is registered Binary, the only to-form a gate-cleared R-tuple carries (P6) — and let `B = {j ≥ 0 : chain_d(j) ∈ coverage(G')}` be the chain indices its to-span covers, a state-independent set fixed by `G'` and the chain alone. `coverage(G') = {t : g ≤ t < g ⊕ ℓ}` is a single T1-interval and the chain ascends strictly, so B is *consecutive*: for `j < j' < j''` with `j, j'' ∈ B`, `g ≤ chain_d(j) < chain_d(j') < chain_d(j'') < g ⊕ ℓ` squeezes `j' ∈ B`. A consecutive subset of ℕ is empty, a finite block, or an up-set `{j : j ≥ j₀}` — and the up-set is realizable: a to-span at the subspace root `g = d.0.s_L` has coverage `{t : g ≼ t}` (PrefixSpanCoverage, ASN-0043), containing every `chain_d(j)` — each retains the prefix `g` by CPP (ASN-0043), whose sibling-advance case applies at `p = #g` because every chain element is T4-valid (above) and every advance's input has length `#g + 1 > p`; this is the ghost-root call of Retraction as an attributed Binary, in chain coordinates.

**Corollary (RangeSterilization).** Let Σ, `d`, `(b, F', G')`, and B be as above.

(i) *Covered frontier deposits are born nullified, whatever type they carry.* Let `Σ →_sh* Σ'` and let a `K.λ_sh`-step homed at `d` fire at Σ' with `f_d^{Σ'} ∈ B`, reaching post-state Θ: by frontier-landing its deposit `(F, G, K)` lands at `a = chain_d(f_d^{Σ'}) ∈ coverage(G')`. The retraction tuple persists into `L_R^Θ` — L12 across each intervening `→_sh`-step by B2's transition-invariant scope, equivalently R3 projected stepwise — so the deposited address, now in `A_rel^Θ`, lies in `nullified(Θ)` (Definition Nullified, ASN-0086 — a pure L-read, shared by B1), and the deposit is excluded from its type's active subset, `(a, F, G) ∉ A_K^Θ` (Definition ActiveSubset). The exclusion is type-blind — `nullified` reads only `L_R` and the candidate address, never the emitted K — and permanent: R6c bars the deposit from the active subset at every `→_sh*`-successor Θ' of Θ, its hypotheses pure L-reads holding at Θ and its path-quantified conclusion transferring by B3 (The projection bridge).

(ii) *Exhaustion only by sacrifice.* The frontier `f_d` moves only at emissions homed at `d`, and then by exactly one: K.σ- and K.α-steps leave L untouched (their frames); a `K.λ_sh`-step homed at `d' ≠ d` adjoins an address with home `d'`, leaving the homed-set of `d` unchanged; and a `K.λ_sh`-step homed at `d` adjoins exactly the frontier slot `chain_d(f_d)`, advancing `f_d` by one (frontier-landing). No emission homed at `d` can route around the block — every one, of every registered type, lands at the frontier. Hence, from any Σ' as in (i) with `f_d^{Σ'} ∈ B` and B finite, induction on `k = max B − f_d^{Σ'} + 1` gives: exactly `k` further emissions homed at `d` — each born nullified by (i), each advancing the frontier by one — bring the frontier to `max B + 1`, the first index past the block. If instead `f_d^{Σ'} < min B`, intervening emissions land below the block, unconstrained by this tuple, until the frontier enters B at `min B` and the count takes over with `k = |B|`. And when B is an up-set there is no exit once the frontier enters B — immediately if `f_d^{Σ'} ∈ B`, otherwise after the `min B − f_d^{Σ'}` emissions below it, unconstrained by this tuple: from entry onward every emission homed at `d` is born nullified — `d`'s link chain is sterilized outright.

(iii) *Resumption is conditional.* Suppose B is finite and exhausted: `f_d^{Σ'} = max B + 1` at some `→_sh*`-successor Σ' of Σ. The next emission homed at `d` lands at `chain_d(f_d^{Σ'}) ∉ coverage(G')`, so *this* tuple no longer blocks it; landing *active*, however, requires the full weakest precondition at Σ': C3's existential must fail over the whole of `L_R^{Σ'}` — no *other* retraction tuple's to-coverage may contain `chain_d(f_d^{Σ'})` — and C2 must hold — the emission must not nullify itself. Escaping one tuple's block is necessary for resumption, not sufficient.

One gate-clearing range-G retraction thus irreversibly sterilizes every unfilled chain slot its to-span covers. Irreversibly, because the block never dissolves: the retraction tuple persists in the audit slice (as in (i)), and `nullified` consults `L_R`, never `A_R` (R6b — a single-state predicate, within B2's scope), so even nullifying the retractor `b` lifts nothing. Whether the substrate should prevent this is left open (Open question 7).

The corollary answers its question under the section's standing configuration — [R] registered Binary — but the framework pins nothing about [R]: the registry is app-composed, and nothing here mirrors ASN-0086's discipline commitment, the layer-level device that did this pinning there. The three remaining configurations settle directly. *[R] unregistered.* Every `Emit_R`, the `Nullify_Binary` wrapper included, fails precondition (i), so no `→_sh`-step grows `L_R`: at every reachable state `L_R^Σ = ∅`, `nullified(Σ) = ∅`, and `A_K^Σ = L_K^Σ` for every registered K, with C2 and C3 holding at every gate-clearing emit (C2 because a registered K with `K ~ R` would itself be a registration of [R]; C3 over the empty `L_R^Σ`) — the substrate is permanently retraction-free. The corner is historical, not degenerate: the published XU.87.1 command set — the system "defined by the commands to which it responds" — contains no link-retraction command [LM 4/61, 4/65–4/70]; udanax-green removes no link from its permanent layers (an arrangement-level delete excises only the document's V-stream entries, leaving the link object and its discovery index intact); and Nelson anticipated the deleted link as a *state*, "not currently addressable, awaiting historical backtrack functions" [LM 4/9], never as a protocol verb. *[R] registered Unary.* Precondition (ii) forces `G = ∅` on every gate-cleared R-tuple, so every `(b, F', G') ∈ L_R^Σ` has `coverage(G') = ∅` and again `nullified(Σ) = ∅`: retraction registered yet inert — each R-emit an audit-slice deposit withdrawing nothing, and the wrapper itself has no `→_sh` image, its `|G| = 1` failing Unary. C2 and C3 again hold at every gate-clearing emit: C2 because a `K ~ R` emit clears the gate only with `G = ∅`, C3 over the empty to-coverages. *[R] registered Multi.* A gate-cleared R-tuple now carries finitely many to-spans, so `coverage(G')` is a finite union of single-span coverages and B a finite union of consecutive sets — one per span, by the squeeze above applied span-wise. Clause (i) holds verbatim, reading only `f_d^{Σ'} ∈ B`; clause (iii) likewise, its existential already ranging over all of `L_R^{Σ'}`. Clause (ii) generalizes componentwise: every emission homed at `d` still lands at the frontier and advances it by one (frontier-landing); emissions whose index falls in a gap of B are unconstrained by this tuple; for bounded B, `max B − f_d^{Σ'} + 1` further emissions carry the frontier past the final block, of which exactly `|B ∩ {f_d^{Σ'}, …, max B}|` are born nullified; and a to-span covering a chain tail makes its component an up-set, sterilizing outright from the frontier's entry into it, as in the conditioned no-exit clause. The freedom itself is design-faithful: on the design evidence region-scale withdrawal, not per-link retraction, is the natural grain — spans of links are first-class [LM 4/24], and a single arrangement-level delete may excise a contiguous run of links — so which configuration to register, single-tuple discipline included, is the app's choice.

## Worked illustration

We fix concrete addresses to check P3 and P4 against a real scenario. Let the content subspace be `s_C = 1` and the link subspace `s_L = 2`. Take a document with prefix `d = 1.1.0.1.0.1` (node `1.1`, user `1`, document `1`; `zeros(d) = 2`). Its content occupies subspace 1:

- `c₁ = 1.1.0.1.0.1.0.1.1`
- `c₂ = 1.1.0.1.0.1.0.1.2`
- `c₃ = 1.1.0.1.0.1.0.1.3`

each an element-level I-address with `zeros = 3`. Write `[x] = {(x, δ(1, #x))}` for the unit-depth singleton endset at `x` — a one-span endset, so `|[x]| = 1` (here `coverage([x]) = {t : x ≼ t}`, by PrefixSpanCoverage).

Consider five registered coverage classes, keyed concretely. Fix a *vocabulary prefix* `w = 1.1.0.1.0.2` — a second document address under the same user, `zeros(w) = 2` — and five ghost element addresses `kᵢ = w.0.1.i`, running `k₁ = 1.1.0.1.0.2.0.1.1` through `k₅ = 1.1.0.1.0.2.0.1.5`, each with `zeros(kᵢ) = 3`. Nothing is stored at any `kᵢ`, nor need `w` be allocated: type endsets are ghost-admissible (L9), and C0 constrains only the stored representatives. Those representatives are the unit-depth singletons `[kᵢ]`; the readable labels remain the app's own (The registry). The app declares:

`Σ_init.registry = {[K_appr] ↦ Unary, [K_succ] ↦ Binary, [K_cit] ↦ Multi, [K_tch] ↦ Multi, [K_retr] ↦ Binary}`

- `approved`: `K_appr = [k₁]`, Unary
- `succession`: `K_succ = [k₂]`, Binary
- `citation`: `K_cit = [k₃]`, Multi
- `touched`: `K_tch = [k₄]`, Multi
- `retract`: `K_retr = [k₅]`, Binary — the app-registered retraction type R (the attributed Binary re-expression of ASN-0086's Nullify, Retraction as an attributed Binary)

For C0: each `[kᵢ]` is one T12-well-formed span (action point `#kᵢ`), hence an `Endset` member, and its coverage `{t : kᵢ ≼ t}` (PrefixSpanCoverage) contains `kᵢ` itself by reflexivity of `≼`, so `[kᵢ] ∈ T_admissible`; the five shape values lie in the catalog; the registry is finite. Key uniqueness is concrete: `kᵢ ⊕ δ(1, #kᵢ)` is the next sibling `kᵢ₊₁` (OrdinalShift increments the terminal component; write `k₆` for `k₅`'s next sibling), so `coverage([kᵢ])` is the half-open interval `[kᵢ, kᵢ₊₁)` — five pairwise disjoint, hence pairwise distinct, coverages: no two keys are `~`-equal.

We walk one decision of precondition (i), which the section's later registration checks abbreviate: the Unary emit below deposits type slot `K = [k₁]`, and (i) runs CoverageEqualityDecidable (Registry permanence) against the stored representatives. Against `K_succ = [k₂]`: the endpoint set is `{k₁, k₂, k₃}` — span starts and next-sibling ends, T1-sorted — and on the cell `[k₁, k₂)` membership differs: `k₁ ∈ coverage(K)` by T2 (`k₁ ≤ k₁ < k₂`), but `k₁ ∈ coverage(K_succ)` would need `k₂ ≤ k₁`, against `k₁ < k₂` — so `K ≁ K_succ`. Against `K_appr = [k₁]`: equal span sets give equal endpoints and equal membership on every cell, so `K ~ K_appr` — (i) holds, and the registry returns `shape(K) = Unary` at key `[K_appr]`.

**Unary.** Emit `(F, G, approved)` with `F = [c₁]`, `G = ∅`. Then `|F| = 1` and `|G| = 0`, so `Sh-conf(approved, [c₁], ∅) = ⊤` and `K.λ_sh` is enabled. The variant `([c₁], [c₂], approved)` has `|G| = 1 ≠ 0`, so `Sh-conf = ⊥`; no `→_sh`-step deposits it into `dom(Σ.L)` at any reachable state (P3).

**Binary.** Emit `(F, G, succession)` with `F = [c₂]`, `G = [c₁]` — "`c₂` supersedes `c₁`." Each endset carries one span, so `|F| = |G| = 1` and `Sh-conf(succession, [c₂], [c₁]) = ⊤`. The two-target variant `G = [c₁] ∪ [c₃]` has `|G| = 2`, failing Binary's `|G| = 1`.

**Multi.** Emit `(F, G, citation)` with `F = [c₁]`, `G = [c₂] ∪ [c₃]` — one source citing two targets. `|F| = 1` and `|G| = 2 < ∞`, so `Sh-conf(citation, [c₁], [c₂] ∪ [c₃]) = ⊤`. (Each of `[c₂]`, `[c₃]` covers a subtree; the span *count* is 2, which is what Multi reads.) The zero-target boundary the table advertises conforms too: `(F, ∅, citation)` with `F = [c₁]` has `|F| = 1` and `|G| = 0 < ∞`, so `Sh-conf(citation, [c₁], ∅) = ⊤`. This Multi tuple is *shape-indistinguishable* from the Unary `([c₁], ∅, approved)` above — same `|F| = 1`, same `G = ∅` — yet it is typed Multi, not Unary; only `citation`'s registration separates the two. Shapes classify registrations, not tuples (Three shapes by G span count).

**Two Multi types coexist (C0).** `citation` and `touched` are both Multi, yet they are distinct registry entries. The registry keys entries by coverage class, not by shape, and C0 (The registry) requires those coverage-class keys be unique — discharged concretely above: `coverage(K_cit) = [k₃, k₄)` and `coverage(K_tch) = [k₄, k₅)` are disjoint, so `[K_cit] ≠ [K_tch]`, and any number of Multi types may so coexist. Emit `(F, G, touched)` with `F = [c₂]`, `G = [c₁] ∪ [c₃]`: `|F| = 1` and `|G| = 2 < ∞`, so `Sh-conf(touched, [c₂], [c₁] ∪ [c₃]) = ⊤` — `⊤` for the same structural reason as `citation`, both reading only `|F| = 1` and `|G| < ∞`. The shapes coincide; the tuples do not. Their type slots carry endsets of distinct coverage class, so the two emits land in distinct typed relations, `L_touched ≠ L_citation` (the type subscript is a coverage-class index, ASN-0086). Shape governs well-formedness; coverage class governs identity. At the opposite extreme C0 permits the *empty* registry `Σ_init.registry = ∅` (`|Σ_init.registry| < ∞` admits 0), which yields a substrate whose *link store* can never grow — *permanently link-inert*: with no type registered at construction and no runtime registration to add one (The registry), precondition (i) of `K.λ_sh` fails for every emit at every reachable state, so `→_sh` can never extend `dom(Σ.L)`. The substrate is not inert outright, only link-inert: `K.σ` and `K.α` are ungated by the registry, so `→_sh` still grows `dom(Σ.M)` and `dom(Σ.C)`.

**State-independence (P4), with ghosts.** Take two reachable states: `Σ`, in which only `c₁` has been stored, so `c₂, c₃ ∉ dom(Σ.C)` — they are ghost addresses; and `Σ'`, reachable from `Σ`, in which `c₂, c₃` have since been stored. The citation emit above references `c₂, c₃`. Evaluate `Sh-conf(citation, [c₁], [c₂] ∪ [c₃])` at each: by P4 the predicate inspects only the span counts `|F| = 1`, `|G| = 2` and `citation`'s registered shape `Multi`, so it returns `⊤` at both `Σ` and `Σ'`, identically. The citation is thus emittable at `Σ` exactly as at `Σ'`, and its ghost targets are admissible (L4/L9).

**Born nullified (gate fires, tuple lands inactive).** We exhibit a concrete witness of the gate-vs-landing separation given at Weakest precondition of the shape-gated emit. Link addresses homed at `d` walk the chain `chain_d` of Range sterilization, enumerated `ℓ₁ = chain_d(0) = 1.1.0.1.0.1.0.2.1`, `ℓ₂ = chain_d(1) = 1.1.0.1.0.1.0.2.2`, then by sibling advance — `a_emit` always the frontier slot (FrontierUnification). Begin at a state `Σ₀` reachable from `Σ_init` in which two citation links already occupy `ℓ₁, ℓ₂` (so `dom(Σ₀.L) = {ℓ₁, ℓ₂}` homed at `d`).

*Step 1 — emit a Binary R-tuple with a non-unit G.* Using the generic gated `Emit_R` (not the unit-depth wrapper of Retraction as an attributed Binary, which could not supply a range G), issue `Emit_R(Σ₀, d, [c₁], G_rng)` with attributing source `[c₁]` (`|F| = 1`) and a *single* range span `G_rng = {(g, δ(3, #g))}` where `g = 1.1.0.1.0.1.0.2.4`; so `|G_rng| = 1` and `coverage(G_rng) = {t : 1.1.0.1.0.1.0.2.4 ≤ t < 1.1.0.1.0.1.0.2.7}`, a contiguous range of three link siblings and their subtrees. The gate fires: (0) the value `([c₁], G_rng, retract)` is a triple; (i) `retract` is registered; (ii) `Sh-conf(retract, [c₁], G_rng) = ⊤` since `retract` is Binary and `|F| = |G_rng| = 1`. This exercises the gap noted in Retraction as an attributed Binary: the gate admits the non-unit Binary `G_rng`. The tuple deposits at the fresh `a_R = a_emit(Σ₀, d) = inc(ℓ₂, 0) = 1.1.0.1.0.1.0.2.3`. Note `a_R ∉ coverage(G_rng)` (`...2.3 < ...2.4`), so even this retraction lands active — it does not nullify itself. Call the post-state `Σ₁`; now `L_retract^{Σ₁} = {(a_R, [c₁], G_rng)}`.

*Step 2 — emit a conforming non-R tuple into the covered range.* Issue `Emit_citation(Σ₁, d, [c₁], [c₂] ∪ [c₃])`. The fresh address is `a = a_emit(Σ₁, d) = inc(a_R, 0) = 1.1.0.1.0.1.0.2.4 = g`. The gate fires again — (0) triple; (i) `citation` registered; (ii) `Sh-conf(citation, [c₁], [c₂] ∪ [c₃]) = ⊤` (`|F| = 1`, `|G| = 2 < ∞`, Multi). So this is a legal `→_sh`-step and the tuple enters the audit slice `L_citation^{Σ₂}`.

*The landing fails.* Yet `(a, [c₁], [c₂] ∪ [c₃]) ∉ A_citation^{Σ₂}`. Trace the inherited wp third conjunct `¬(∃ (b, F', G') ∈ L_R^{Σ₁} :: a_emit(Σ₁, d) ∈ coverage(G'))`: the retraction tuple `(a_R, [c₁], G_rng) ∈ L_R^{Σ₁}` has `a = g ∈ coverage(G_rng)` (since `g` is the lower endpoint of the half-open range), so the existential holds and the conjunct is *false*. By ASN-0086's `nullified`/`A_K` machinery the citation is born nullified: `a ∈ nullified(Σ₂)`, hence `(a, [c₁], [c₂] ∪ [c₃]) ∉ A_citation^{Σ₂}`. The gate did not reject this call — all of (0), (i), (ii) held — the wp's inherited third conjunct did.

*The poisoning is a block, not a slot.* The scenario instantiates Corollary RangeSterilization (Range sterilization). In chain coordinates `ℓ₁ = chain_d(0)`, `ℓ₂ = chain_d(1)`, `a_R = chain_d(2)`, and `coverage(G_rng)` meets the chain in the finite block `B = {3, 4, 5}` — `chain_d(3) = 1.1.0.1.0.1.0.2.4 = g` through `chain_d(5) = 1.1.0.1.0.1.0.2.6`. After Step 1 the frontier is `3 ∈ B`, so clause (ii)'s count is `k = 5 − 3 + 1 = 3`: the next three emissions homed at `d`, of any registered type, are born nullified — Step 2's citation at `chain_d(3)` is the first sacrificial deposit, with `...2.5` and `...2.6` still to fill before the frontier exits at `chain_d(6) = ...2.7`. Resumption there is conditional (clause (iii)): no `L_R` tuple at the exhausted state may cover `...2.7` — true here, since `...2.7 ∉ coverage(G_rng)` and `L_retract^{Σ₂}` holds no other tuple, provided the two remaining sacrificial deposits add none that covers it — and the resuming emission must satisfy C2.

## Open questions

The following are left for the successor note that layers operational semantics on this framework:

1. **Idem semantics at emit.** What must the substrate guarantee when an app re-emits a tuple "the same as" an existing active tuple of a type a successor registry marks idempotent, and what is the criterion of sameness?

2. **Behavior catalog.** Which substrate-provided behaviors (read-filter, transitive-closure, typed-reverse-lookup, age-staleness) compose with which shapes, and what predicates does each unlock?

3. **Default predicates.** What predicates does every registered type receive by virtue of its shape and any idem flag a successor registry carries, independent of any behavior?

4. **Standard registrations.** Does the substrate ship any types pre-registered, or is each substrate's `Σ_init.registry` composed entirely of app-declared entries?

5. **Predicate composition.** What composition rules govern the atomic predicates each type receives?

6. **Extension beyond F=1 and N=3.** What path serves an app that needs a multi-span source (from-*span-count* `|F| ≥ 2`, for a source spanning disjoint passages within an arity-3 tuple) or richer *arity* (slot count `N > 3`) — a supplemental note loosening the constraints here, or a parallel framework?

7. **Sterilization containment.** Must the substrate prevent a gate-clearing retraction's coverage from reaching a home chain's unfilled emission slots (Corollary RangeSterilization), or is avoiding sterilization an app obligation?
